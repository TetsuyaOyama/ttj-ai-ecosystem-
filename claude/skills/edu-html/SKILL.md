# edu-html：教育用インタラクティブ HTML

「SDV 通信道場」型の教材。**1ファイル完結**（外部 JS/CSS/画像に依存しない。フォントのみ可）で、ブラウザで開くだけで動く。

## 構成（この順で作る）

1. **ヘッダー**：教材名、対象者、所要時間、学習目標（3つ以内）
2. **章ナビ**：左サイド（スマホでは上部）に章一覧。現在位置をハイライト。進捗バー付き
3. **本文の章**：1章 = 1テーマ。「要点 → 図（SVG）→ 例 → ひとことまとめ」
4. **クイズ**：章末に2〜4問。選択式で、押すとその場で正誤と**解説**を表示。全問回答でスコア表示
5. **用語集**：本文中の用語をクリックで説明表示、巻末に五十音/ABC順の一覧
6. **フッター**：作成者（TTJ）、更新日、参考資料

## 実装の決まり

- デザインは ttj-design スキルに従う（tokens.css の変数を `<style>` に埋め込む）。
- JS は素の JavaScript。データ（章・クイズ・用語）は `<script>` 内のオブジェクトにまとめ、HTML 生成と分ける。
- 進捗・回答は `localStorage` に保存してよい（失敗しても動くよう try/catch）。
- キーボード操作（章移動・クイズ選択）とフォーカス表示に対応。`aria-label`、`lang="ja"`。
- 印刷用に `@media print` を用意（ナビを隠す）。
- 通信図は telecom-svg スキルの規約で作った SVG を埋め込む。
- 実名・個人情報・社外秘の情報（所属先の内部仕様など）を入れない。一般公開されている仕様の範囲で書く。

## チェックリスト

- [ ] ファイル単体で動く（外部依存なし）
- [ ] 章ナビ・進捗・クイズ・用語集がすべて動く

- [ ] スマホ幅で崩れない
- [ ] コンソールエラーがない
