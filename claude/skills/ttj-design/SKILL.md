# ttj-design：紺×金 TTJ デザイン

## 手順

1. `design-system/tokens.css`（リポジトリ内。無ければ ttj-ai-ecosystem/design-system/ から取得）を読み、**変数名を確認**する。
2. 作るページの `<head>` で tokens.css を読み込む（1ファイル完結にしたい場合は `<style>` に内容を貼り込む）。
3. 色・余白・角丸・影・フォントは**すべて CSS 変数**で指定する。`#0B1F3A` のような直書きはしない。
4. 部品（ボタン・カード・見出し・表・コード）の書き方は `design-system/components.html` を手本にする。
5. 作ったら下のチェックリストで自己点検する。

## 基本の考え方

- 基調は **紺（背景・見出し）＋金（アクセント）**。金は「ここを見てほしい」所だけに使い、面積を広げすぎない。
- 本文は読みやすさ優先：明るい背景に濃い文字、または紺背景に明るい文字。コントラスト比は 4.5:1 以上。
- フォントは `Noto Sans JP`（本文・UI）と `Noto Serif JP`（見出し・引用）。
- 余白は広めに。行間は本文 1.8 前後。

## チェックリスト

- [ ] tokens.css を読み込んでいる（または全文を埋め込んだ）
- [ ] 色の16進直書きがない（変数経由）
- [ ] `<html lang="ja">`、`<meta charset="utf-8">`、`<meta name="viewport">`、`<title>` がある
- [ ] 見出しの階層が正しい（h1 は1つ、飛ばさない）
- [ ] 文字と背景のコントラストが十分（金文字を白背景に置かない）
- [ ] 画像に `alt` がある
- [ ] スマホ幅（360px）で横スクロールしない
- [ ] ボタン・リンクにフォーカス表示がある
- [ ] 外部ライブラリを使っていない（フォントの読み込みを除く）
- [ ] 実名・APIキー・個人情報が入っていない
- [ ] 公開前は checker → codex-review（publish スキル参照）
