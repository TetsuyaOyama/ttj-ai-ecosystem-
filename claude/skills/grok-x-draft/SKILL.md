# grok-x-draft：X 投稿の清書

Grok Bot（`bots/grok-bot/run.py --task xpost|news`）が `drafts/YYYY-MM-DD-<task>.md` に出した下書きを、投稿できる形に整える。**投稿は人が行う。Claude は X に投稿しない。**

## 手順

1. `bots/grok-bot/drafts/` の最新ファイルを探す（`ls -t`。数が多ければ scout に任せる）。
2. 下書きを読み、案ごとに事実関係を確認する。**Grok の出力は裏取りが必要**：数字・固有名詞・日付・引用は、根拠が示されていなければ「要確認」と付ける。
3. 各案を清書する：
   - 1ポストは**全角140字以内**を目安（長文投稿を使う場合は別扱いと明記）
   - 冒頭の1行で要点。ハッシュタグは 0〜2 個
   - 専門用語は噛み砕く。煽り・断定・他者攻撃・投資の断定的な助言は書かない
   - 実名・社外秘・所属先の内部情報を出さない
4. 出力形式：案ごとに「清書案／文字数／要確認事項」を示し、おすすめを1つ選ぶ。
5. 人が選んで投稿する。必要なら修正依頼を受けて再清書する。

## 決まり

- 元の下書きファイルは書き換えない。清書は別ファイル（`drafts/YYYY-MM-DD-<task>-final.md`）か会話内に出す。
- 相場に関する話題は「個人の見解・投資助言ではない」旨を添えるか、事実のみにとどめる。
- キーや .env に触れない（Bot が自分で読む）。
