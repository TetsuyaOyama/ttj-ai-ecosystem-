# memoir-editing：四次元手記の編集ルール

四次元手記は、ユーザー本人の人生を綴った日本語の自伝 HTML。**「99%事実、残りは軽いAI味付け」**が原則。

## 色分けのルール

- **琥珀色（#FFBF00 系）**：AI が創作・補足した部分（情景描写、心情の補い、つなぎの文など）
- **生成り色**：事実（本人が語った出来事・日付・場所・数字）
- 迷ったら琥珀色にする。事実を琥珀にするのは許容、**創作を生成り色にするのは禁止**。
- AI 創作は軽い味付けにとどめる。出来事・数字・因果関係を新しく作らない。

## 守ること

1. **実名は必ず伏せる。** 人名・会社名・学校名・地名の細部は、仮名・イニシャル・「ある会社」などに置き換える。家族・同僚・取引先・契約相手を含む。迷ったら伏せる。
2. **章構成を崩さない：プロローグ＋第1章〜第15章＋エピローグ。** 章の追加・削除・順序変更・統合をしない。章内の加筆は可。
3. **フッターの真正性表記を保つ。** （事実と AI 創作の色分けを説明する注記）削除・弱体化しない。
4. 文体は既存の章に合わせる（一人称・文末・時制）。新しい口調を持ち込まない。
5. 個人情報（住所・電話・口座・病歴の詳細・係争の具体的な情報）を新たに書き足さない。

## 作業手順

1. 対象章を読み、琥珀色の記法（クラス名・style）を grep で確認する。
2. 編集する。事実の追加は本人に確認した内容のみ。
3. 編集後チェック：
   - [ ] 新規の創作部分が琥珀色になっている
   - [ ] 実名が入っていない（固有名詞を grep で再確認）
   - [ ] 章の数・順序が変わっていない
   - [ ] フッターの真正性表記が残っている
   - [ ] HTML が壊れていない（checker に回す）
