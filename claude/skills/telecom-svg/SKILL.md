# telecom-svg：通信の SVG 図

対象の図：**VoLTE 通話フロー／S8HR ローミング／SMS over SGs・NAS・IP／3G・4G・5G 比較**。

## 共通の規約

- 単体で開ける1つの SVG（または SVG を埋め込んだ1ファイル HTML）。`viewBox` を指定し、幅は可変にする。
- 配色は TTJ（design-system/tokens.css の紺×金）。背景は紺または白、線・文字は変数に合わせた色。金は「注目してほしい信号・経路」だけ。
- フォントは `Noto Sans JP`。ラベルの最小サイズは 12px 相当。
- 日本語の説明文は短く。**ラベル（ノード名・メッセージ名）は 3GPP 用語**をそのまま使う：UE, eNB, MME, SGW, PGW, HSS, PCRF, P-CSCF, S-CSCF, I-CSCF, IMS, AS, MSC, SGs, IWF, SMSC, VPLMN, HPLMN など。メッセージは `INVITE`, `183 Session Progress`, `PRACK`, `180 Ringing`, `200 OK`, `ACK` など原語表記。
- 3GPP の仕様番号（TS 23.228 など）を図の注に添えられる場合は添える。不確かな場合は書かない。

## シーケンス図の描き方

- 左から右へ、登場者（ノード）を縦の**ライフライン**（破線）で並べる。登場者は 5〜7 まで。
- メッセージは水平な矢印。**時間は上から下**へ。実線＝要求、破線＝応答。矢印の上にメッセージ名、下に必要なら補足。
- 上から下に連番（①②③…）を振り、本文の説明と対応させる。
- フェーズ（登録／呼設定／通話中／切断）は薄い帯と見出しで区切る。
- ローミング図は、VPLMN と HPLMN を枠で囲み、境界（S8 インターフェース）を明示する。S8HR ではホーム側 IMS を経由せず**訪問先 PGW で折り返す**ことが分かるように経路を色分けする。
- SMS 図は方式（SGs／NAS／IP）ごとに経路を並べて比較できる構図にする。

## 凡例（必須）

どの図にも凡例を入れる：線種（要求／応答／ユーザープレーン／シグナリング）、色の意味、略語の一覧。凡例の無い図は未完成として扱う。

## 出力前のチェックリスト

- [ ] viewBox 指定あり、`<title>`/`<desc>`（アクセシビリティ用）あり
- [ ] 用語・メッセージ名が 3GPP の表記と合っている
- [ ] 時間の向き（上→下）と連番が一貫している
- [ ] 凡例がある
- [ ] 色が TTJ 配色で、色だけに意味を頼っていない（線種・ラベルでも区別）
- [ ] 文字が重なっていない・はみ出していない
- [ ] checker で XML として正しいか確認した
