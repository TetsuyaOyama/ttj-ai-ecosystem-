# 記憶メモ（~/.claude/memory/MEMORY.md）

セッション開始時に先頭40行が自動で読み込まれます。**重要な決まりは上の方に**書くこと。
新しい決まり・好み・ハマりどころが出たら、1行ずつ書き足す。古くなったら消す。
秘密情報（APIキー・パスワード）や個人情報は書かない。

## 基本の決まり

- 応答・コメント・README は日本語。コードの識別子は英語。
- モデル振り分けは CLAUDE.md の表に従う。切り替えは人が行うので、必要なときは時期と切り替え先を伝える。
- APIキーは ~/.claude/skills/.env の1か所。Claude は .env を直接読まない。
- 公開前は checker → codex-review の順。
- push / deploy / rm は人の確認を取る。
