Claude Code 環境の全体図：依頼から公開まで、左から右へ

人（ビッグマウンテンテツヤ）の依頼が、入口 → 司令塔（Claude Code）→ ハーネス（harness：安全柵）→ 振り分け → スキル（skill）→ サブエージェント（subagent）→ 道具・API → 公開 と流れます。ボックスを押す（Tab で移動）と、役割・実ファイルのパス・要点が下に出ます。

モデル振り分け（エージェントの色）

    色のボタンを押すと、そのモデルのエージェントだけが強調されます。上位モデルは最初から使わず、軽い側から試します。
