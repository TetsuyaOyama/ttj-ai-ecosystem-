1. 実務者のチェックポイント CHECKPOINTS

通信・車載の実務者が、競合と業界の動きを短時間で確認するための章である。まず10点を読み、続けて、数字の食い違い、今後の予定、未確認の点を見る。

1.1 いま押さえる10点

各項目は、公開資料に載った事実だけで書いている。数字は各社の自己申告であり、第三者の検証は受けていない。

  1. SGP.32 の商用提供が、事業者ごとに出そろい始めている。
    Telenor は SGP.32 SIM の出荷を 2026年4月17日に開始し[98]、SORACOM は対応 IoT SIM を 2026年7月7日に商用提供した[14][46]。AT&T（2025年10月30日ごろ）[78]、Telefónica Tech（2026年7月9日）[88]、Aeris（2026年10月2日）[111]も対応を発表している。
  2. 車載での eSIM 採用の公表が、供給者側から出ている。
    G+D、Rivian、AT&T は、Rivian R2 に SGP.32 対応 eSIM と 5G を導入すると 2026年2月3日に発表した[131]。IDEMIA は Hyundai Motor Group への eSIM 提供を 2026年2月24日に発表したが、準拠規格が SGP.32 か SGP.22 かは未確認である[132]。
  3. 国内勢の SGP.32 は、まだ先の日付である。
    KDDI の SGP.32 提供は 2026年度下期（2026年10月〜2027年3月）とされる[46][47]。docomo business SIGN「Pro」は SGP.32 に対応し、2027年3月予定だが、どちらも自動車向けの記述は見つかっていない[46][24]。
  4. BMW をめぐり、国内2社の名前が別々の形で出ている。
    NTT ドコモビジネスが BMW の次世代 EV の通信を受注したと 2026年3月に報じられた（100カ国超、米中を除く）が、NTT 側の一次発表は見つからず報道のみである[26][27]。Verizon は 2026年7月9日、BMW Group の米国新車の接続を、KDDI の Global Communications Platform を使って提供すると発表した[81]。
  5. 自動車単独の接続台数を公表する事業者は少ない。
    Cubic3 は 2,900万回線（現行ページ、日付なし）で、自動車や建機などの車両向けの数字であり、単位は「回線」である[1]。Aeris は 4,500万台（2026年10月2日、自社申告）[111]、Tata MOVE は 250万台（時点の記載なし）[108]である。KDDI の 6,300万回線超（2026年6月末、KDDI 提供の PR 記事）は、自動車以外を含む全社の IoT の数字である[43]。
  6. 恒久ローミングの規制は、国ごとに状況が違う。
    ブラジルの Anatel は 2026年8月6日、IoT/M2M 向けの恒久ローミング規則の判断を保留して追加調査に切り替えたと報じられた[139]。インドの DoT は 2025年6月26日の指示で、M2M eSIM の SM-SR を政府が定める事業者のみが運用できるとした[140]。
  7. 衛星は、自動車では検証とデモの段階の発表が中心である。
    Deutsche Telekom は 2026年9月17日に Iridium を加えたマルチオービット IoT ローミングを発表し、トヨタ車を使った音声メッセージのデモを行った[69]。5GAA のロードマップでは、衛星接続の量産車への搭載は 2027年ごろとされる[143]。
  8. 次世代 eCall と停波が、車載機器の対応時期に関わる。
    欧州委員会の改正案では、次世代 eCall を 2027年1月1日にすべての新車（M1、N1）へ適用する。最終公布版の日付は未確認である[146]。NTTドコモの 3G は 2026年3月31日に終了し、一部の LTE 機器で LTE 通信ができなくなる事象も案内された[150]。
  9. OEM 向けの Wi-Fi と課金を API で渡す動きが複数ある。
    Telenor の IoT Drive（2025年9月8日発表）は、OEM が Wi-Fi やデータパッケージをエンドユーザーに提供できる API を備える[95]。Vodafone の Internet in the Car は、車両価格に含める形とプリペイドの2形態で、2026年6月2日時点で 30か国以上とされる[61][62]。SORACOM の課金の章（第8章）と並べて読める。
  10. 料金と顧客名は、公表されていない例が大半である。
    自動車向けで金額が出ていたのは、Deutsche Telekom の MobilityConnect（月額 9.95ユーロ、ドイツ、BMW iX 向け）など少数である。発表日の記載がなく、現行の料金かは未確認である[71]。ほかは 2019年や 2022年の個人向けの古い例にとどまる[87][28]。Cubic3 は標準価格の記載なし、SORACOM は個別見積りと明記されている[10]。Aeris は OEM を30社超とするが、社名は出していない[110]。

  • 1人ひとりに合わせた車内体験：車両購入者や運転者のサービス利用状況をもとに詳細なプロファイルをAIで生成・分析し、行動傾向やニーズを可視化。潜在的なアップセル機会やターゲットを絞ったマーケティング施策の立案を支援。

8.1 マルチPDN／マルチAPN——1枚のSIMで複数の通信セッションを独立管理

従来のIoT SIMは、1枚のSIMに対して1つのAPN（Access Point Name）で1つのPDN（Packet Data Network）接続を利用するのが基本だった。マルチAPN（マルチPDNサポート）は、1枚のSIMで複数の通信セッションを同時に確立できる機能で、各セッションは独立したPDN接続を持つ。

  • 自動車制御システムのトラフィックは VPG 経由で閉域網に接続し、OEMバックエンドと直結。外部インターネットとは完全に分離したセキュアな通信路を確保
  • In-Car Wi-Fi のトラフィックはインターネットへ直接抜け、エンドユーザーの利用量を個別に計測
  • 音声・ビデオ通話は独立したPDN接続で処理

従来「複数SIMを搭載したり、用途ごとに別の通信デバイスを用意したりする」ケースもあったが、1枚のSIMで解決できる。さらに通信宛先ごとの通信量を個別に集計する Detailed Stats と組み合わせることで、「自動車メーカーが車両にアクセスするための通信」と「エンドユーザーによるインフォテインメント等の通信」の利用量を明確に分離でき、これがダウンストリーム課金の基盤になる。

8.2 ダウンストリーム課金プラットフォーム——OEMが料金設計を握る

コネクテッドカーの通信ビジネスでOEMが本当に難しいと感じるのは「通信の課金をどう設計するか」である。In-Car Wi-Fiを使った分だけ課金したい、月額プランと従量プランを使い分けたい、上限到達時に追加データを購入できるようにしたい、請求書発行や決済は自社ブランドで行いたい——これらをゼロから構築すると、料金計算エンジン・請求書発行・決済基盤・通信制限ロジックを個別に開発・運用することになる。本プラットフォームはそれを引き受ける。

通信宛先別の利用量計測と自由な料金モデル設計

Detailed Stats と連携し、通信宛先やユースケースごとに利用量を個別計測。「In-Car Wi-FiはGB単位の従量課金」「音声通話は月額固定」といった用途別の料金モデルを自由に設計できる。特定アプリケーションへの課金をキャンペーンで割引したり、プレミアムオプションとして In-Car Wi-Fi を基本サービスと分けたりするサービス設計も可能。

8.3 SORACOM Connectivity Hypervisor（SGP.32）——長期稼働を支えるeSIM管理

製造時に書き込んだSIMのProfileが、10年後の法規制変更や事業環境の変化に対応できるか——これはコネクテッドカーにとって避けられない課題である。Connectivity Hypervisor は、GSMAのeSIM新規格 SGP.32 に準拠したオーケストレーション層（プロファイル管理をまとめて引き受ける層）で、1枚のSIMに載せるProfileをOTAで遠隔から追加・切替・削除できる。ユーザーコンソールやAPIから、プロファイルの追加、有効プロファイルの切り替えと削除、主プロファイルが使えないときのフォールバック先（退避先）の指定が可能。他の通信事業者が提供するプロファイルも扱える。

  • 現地規制の変更時には現地キャリアのProfileに切り替え
  • 廃車・転売時には不要なProfileを削除

13.3 車載の衛星通信（NTN）と 5GAA

  • 3GPP：NTN は Release 17 で初めて正式に規格化された（NR-NTN は透過型ペイロード、FR1 の FDD など）。IoT-NTN（NB-IoT、eMTC）も Release 17 から整備された。Release 18 でバンド追加、Ka 帯対応、NTN-TN 間のモビリティなどが進み、Release 19 で再生型ペイロードや RedCap 対応を検討している。[142]
  • 5GAA：2025年5月15日のパリのデモで、IoT NTN（Release 17 ベース）の公道デモを行った。参加には BMW、Stellantis、Cubic3、Skylo、Viasat、Qualcomm、MediaTek などがある。5GAA のロードマップでは、衛星接続の量産車への搭載は2027年ごろ、5G-V2X は2026〜2029年ごろ。[143]
  • 5GAA：2026年2月5日のサクラメントのデモで、BMW、HARMAN、Qualcomm、Viasat、Fraunhofer が、NB-IoT 経由の双方向音声通話を実演した。[144]
  • ESA 白書（2025年7月）：地上網の圏外時間の目安は、トラックで走行時間の約10%、乗用車で約5%。ESA と 5GAA が Release 19 に向けて、端末設計、アンテナ、モビリティ処理を共同で提言した。課題として、ハンドオーバー時のセッション継続、ドップラー補正、アンテナのコスト、消費電力、周波数帯、事業採算性を挙げる。[145]

事業者の動きは各社の章にある。Cubic3（第6章）、Deutsche Telekom（第10章、2026年9月17日）、Vodafone（2026年2月6日と11月10日の報道）、KDDI（au Starlink Direct for IoT）、AT&T（AST SpaceMobile、報道）などである。第11章の専業・プラットフォーム各社（Aeris、Tata、Airnity、KORE、floLIVE、1NCE、Telit）では、衛星対応の公表が確認できなかった。

15. 用語集

上から12行は初版のまま。その下は、2026年11月14日の改訂で加えた語である。

用語説明
SDV（Software Defined Vehicle）主にインターネットに接続されたソフトウェアを通して機能を更新することができる車両
OTA（Over-The-Air）無線通信を介したソフトウェアやファームウェアなどのアップデートを含む、車両とデータの送受信を行う技術
NTN（Non-Terrestrial Network）衛星通信をはじめとする非地上系ネットワーク。地上系ネットワーク（TN）と対比される
UTX（Ubiquitous Transformation）ソフトバンクが推進する、地上ネットワークとNTNを融合し「いつでもどこでもつながり続ける世界」を目指す構想
eUICC / eSIM / iSIMプロファイルを遠隔で書き換え可能なSIMの形態。iSIMはチップに統合された形態
SGP.32GSMAが策定したIoT機器向けeUICC規格。任意のタイミングで通信プロファイルを配信・管理し、リモートでの切り替えが可能。デバイスやSIM上で動くIPA（IoT Profile Assistant）が、eIMやSM-DP+といったコンポーネントと通信し、プロファイルの配信・有効化・無効化・削除・フォールバックを制御する
APN / PDNAPN（Access Point Name）は接続先の識別名、PDN（Packet Data Network）はデータ通信の接続（セッション）。マルチPDNは1枚のSIMで複数のPDN接続を同時確立する機能
VPG（Virtual Private Gateway）SORACOMの閉域網接続機能。柔軟なアクセス制御とあわせて、OEMバックエンドとのセキュアな通信路を提供
Local Profile常時ローミングが規制されている地域で用いる、現地MNOの通信プロファイル
eCall事故時などに車両から緊急通報を行う仕組み
5GAA5G Automotive Association。自動車と通信の連携を推進する業界団体
ダウンストリーム課金通信の費用負担者（OEM／サービス事業者／エンドユーザー）ごとに利用量を分けて扱い、エンドユーザーへの課金・請求・支払い処理までを行う仕組み
SGP.02 / SGP.22GSMA の eSIM 規格。SGP.02 は M2M 向け、SGP.22 はコンシューマ向け。SGP.32 は IoT 向けで、これらと並べて語られる。
eIM（eSIM IoT Remote Manager）SGP.32 で、プロファイルの遠隔管理を担う基盤。「eIMaaS」は、これをフルマネージドで提供する形。誰が運用するかが論点になる。
SM-SR / SM-DP+SIM のプロファイルを管理・配信するサーバー。インドの DoT 指示は、M2M の eSIM で SM-SR の所有と運用を政府が定める事業者に限る。
eSA / SAS-SMGSMA の認証。eSA は eUICC のセキュリティ保証、SAS-SM はサブスクリプション管理側の認定。
SGP.41 / IFPPIFPP（In-Factory Profile Provisioning）は、工場でプロファイルを書き込む方式。Orange、IDEMIA、Acceleronix の発表は、SGP.41 に準拠し SGP.32 基盤上で動作するとしている。
単一 SKU地域別に SIM の品番を分けず、1つの品番で世界に出荷すること。Rivian、SORACOM、Telenor、Aeris などの発表に出る。
恒久ローミング外国の SIM が、長期にわたって他国の網に接続し続けること。ブラジルの Anatel は、同一事業者網に連続90日滞在することと定義する基準を決めた（2024年10月17日）。
ローカルブレイクアウト / マルチ IMSIローカルブレイクアウトは、現地の網の近くでインターネットへ出す方式。マルチ IMSI は、1枚の SIM に複数の加入者識別を持たせる方式。floLIVE の発表に出る。
RSP（リモート SIM プロビジョニング）SIM のプロファイルを遠隔で書き込み、切り替える仕組みの総称。Airnity が使う語。
MVNO / フル MVNO自社の無線網を持たず、他社の網を借りて通信を提供する事業者。フル MVNO は、コア網を自社で持つ形。Airnity と Transatel が該当する。
MNO自社の無線網を持つ移動体通信事業者。
GEO / LEO / HAPS静止軌道の衛星、低軌道の衛星、高高度プラットフォーム（成層圏の基地局）。NTN の構成要素。
NB-IoT NTN低消費電力の IoT 規格 NB-IoT を、衛星経由で使う方式（3GPP Release 17 から）。Skylo、Vodafone、Deutsche Telekom の発表に出る。
PSAP緊急通報の受付機関。次世代 eCall では、4G/5G の IMS 経由の通報を処理できる必要がある。
次世代 eCall（NG eCall）4G/5G の IMS パケット交換網で行う eCall。現行の eCall が 2G/3G を使うことへの対応である。
UN-R155 / R156UNECE が定めた、車両のサイバーセキュリティ規則（R155）とソフトウェアアップデート規則（R156）。
CSMSサイバーセキュリティ管理システム。R155 が自動車メーカーに求める管理の仕組み。
5G RedCap5G の機能を絞って低コスト化した規格。Release 17 で導入され、Release 18 の eRedCap でさらに簡素化された。
ネットワークスライシング1つの物理網を、用途別の仮想的な網に分ける技術。5GAA が車載のユースケースを整理している。
MEC利用者に近い場所で処理を行うエッジコンピューティング。Verizon の V2X プラットフォームに出る。
V2X車と、車、道路、歩行者、網などとの通信の総称。
Split Billing / Consumer BillingSORACOM の英語圏の発表での呼称。Split Billing は用途別に通信コストを分けること、Consumer Billing はエンドユーザーへ直接課金すること。
