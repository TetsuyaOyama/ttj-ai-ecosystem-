この章で分かること

  1. SSD（Solid State Drive）と HDD（Hard Disk Drive）の仕組みの違いと、電源を切っても残る記憶というストレージの役割を説明できる。
  2. SSD の接続（SATA〔Serial ATA〕と NVMe〔Non-Volatile Memory Express〕）と、M.2 という形を区別して、仕様表を読める。
  3. 速さ・寿命（書き込める総量の目安）・容量の表示が、条件や定義つきの値であることを理解し、読み違えを避けられる。

前提：第03章（マザーボードと規格）、第04章（メモリ）。

ストレージは、電源を切っても残る記憶

ストレージ（storage）は、データを長く置く記憶です。電源を切っても、中身は残ります。メインメモリ（第04章）は、電源を切ると消えます。OS（Operating System）やソフト、写真、文書は、ストレージに置きます。

PC のストレージは、おもに SSD と HDD の 2 種類です。サーバー向けの形や、NVMe のキューの仕組みは、計算サーバー講義 第09章で扱います。この章では、PC で使う形と接続だけを扱います。

SSD と HDD：仕組みの違い

SSDは、フラッシュメモリ（flash memory）にデータを書く記憶です。回転する部品がありません。HDDは、回転する円盤に、磁気でデータを書く記憶です。

どちらが良いかは、用途で決まります。ここでは優劣を示しません。大容量の保管と、速い読み書きを、分けて考える人もいます（一般知識）。

SSD の接続：SATA と NVMe

SATAは、ドライブをつなぐ接続の規格です。SATA-IO（SATA International Organization）が発行します。SATA-IO は、名前を「SATA 6Gb/s」「SATA Revision 3.x」と書くよう案内していて、「SATA III」「SATA 3.0」は使わないよう求めています。ホームページが現行として載せる版は、SATA Revision 3.5 です。

NVMeは、SSD を PCIe（PCI Express）経由で効率よく使うための、命令とインターフェースの規格です。NVM Express, Inc. が発行します。公式ページは、NVM Express Base Specification の版 2.4 を、2026 年 7 月 31 日に承認し、8 月 4 日に公開した、と記しています。SSD ごとに、対応する版は違います。

NVMe で読み書きするとき、要求は、アプリケーションから SSD の中のフラッシュメモリまで、いくつかの層を順に通ります。図で、NVMe がどの層にあるかを見てください。

形：2.5 インチと M.2

SSD の形には、HDD と同じ大きさの 2.5 インチ型と、小型の基板の M.2（エムドットツー）があります。M.2 は、基板の M.2 スロットに直接差す形です。

M.2 の表記には、幅と長さ、キー、接続、方式が並びます。次の図で、例の表記を分解します。

大切なのは、M.2 は形の名前で、接続の名前ではないことです。同じ M.2 の形でも、PCIe の NVMe の製品と、SATA 方式の製品があります。スロットが対応する接続と長さは、マザーボードの仕様表で確かめます（第03章）。

性能の言葉：速さの数字の読み方

SSD の速さは、順次の読み書き（大きなデータを続けて）と、ランダムの読み書き（小さなデータをあちこちへ）で分けて示されます。ランダムの読み書きは、1 秒にこなせる回数（IOPS、Input/Output Operations Per Second）で表すことが多くあります。

メーカーの公開値は、条件つきです。Samsung Electronics（韓国）の 990 PRO のデータシート（版 2.0、2023 年 7 月）は、順次の読み出しと書き込みの最大の値を載せたうえで、測定に IOmeter（測定のソフト）の版 1.1.0 を使ったこと、実際の性能は変わりうることを書いています。数字だけを見て、製品の間で比べません。測定の条件と、自分の使い方に近いかを確かめます。

もう 1 つの言葉が、DRAM キャッシュです。SSD の中の DRAM（Dynamic Random Access Memory）に、管理の情報などを置く仕組みです。990 PRO のデータシートは、LPDDR4（低電力の DRAM の規格）の DRAM を載せると書き、990 EVO Plus のデータシート（版 1.0、2024 年 10 月）は、キャッシュの欄に HMB（Host Memory Buffer）と書いています。HMB は、PC 側のメモリの一部を使う仕組みです。製品によって、構成が違います。

寿命の指標：TBW

TBW（Terabytes Written）は、書き込める総量の目安を、テラバイトで表した指標です。Samsung の 990 PRO のデータシートは、容量の違う型番で 600・1,200・2,400 TB と書き、保証は 5 年と書いています。保証は、年数と TBW の、先に達したほうで切れます。

JEDEC（半導体の標準化団体）は、2010 年の発表で、JESD218 が SSD の耐久性の指標として TBW を定め、クライアント向けと企業向けの区分を持つ、と書いています。指標の定義と、保証との関係は、メーカーごとに違います。購入前に、データシートと保証規定を読みます。

容量の表示の違い

製品の容量は、10 進で表示されます。1 GB は 1,000,000,000 バイトです。Samsung のデータシートは、この定義（IDEMA の定義）を書き、使える容量は違うことがある、と注記しています。2 進の単位（GiB）では、1 GiB は 1,073,741,824 バイトです。OS の表示の単位は、OS ごとに確かめます。この講座では、OS の表示の単位を断定しません。

温度と、ヒートシンク

M.2 の SSD も、読み書きで熱を持ちます。990 PRO のデータシートは、動作温度を 0〜70 ℃ と書いています。高い温度が続くと、速度が下がる製品があります（一般知識）。ヒートシンクの要否と取り付けは、SSD と基板のマニュアルに従います。

演習：3 つのスロットと 3 つの SSD を組み合わせる

次は、架空のマザーボード Z の M.2 スロット 3 つと、3 つの SSD の仕様です。それぞれの SSD を、どのスロットに差せばよいでしょうか。理由も答えてください。

答えを見る

答えは、SSD ウ は M.2_3、SSD ア は M.2_1、SSD イ は M.2_2 です。まず、長さ 110 mm の SSD ウ を受けられるのは M.2_3 だけです。次に、PCIe 方式の SSD ア は、PCIe に対応する M.2_1 に差せます。最後に、SATA 方式の SSD イ は、SATA に対応する M.2_2 に差せます。M.2_1 は SATA 方式に非対応なので、SSD イ は差せません。

考え方は、条件の厳しいものから決めることです。（すべて架空の仕様です。実際の基板では、仕様表と脚注で確かめます。）

つまずきやすい点

M.2 の SSD でも、SATA 方式の製品があります。形だけで決めず、接続と、スロットの対応を確かめます。

製品の速さの数字は、条件つきの最大の値です。測定の条件を読み、実際の使い方で同じ速さが出るとは限りません。

TBW は、速さの指標ではありません。書き込める総量の目安で、定義と保証との関係は、メーカーが決めます。

容量が少なく見えるのは、故障とは限りません。製品の表示は 10 進で、使える容量や OS の単位と違うことがあります。

ストレージの初期化や交換で、データが消えることがあります。作業の前に、必要なデータの写しを取ります（第24章）。

自分の 1 台でのつながり

選ぶとき：基板の M.2 スロットの対応（長さ・接続）を先に確かめ、SSD の仕様表と照らします。組むとき：M.2 のスロットの位置とネジ、ヒートシンクの付き方を、基板のマニュアルの図で見ます。直すとき：ドライブが認識されない症状では、接続の種類と、スロットの共有の脚注（第03章）を疑います。
