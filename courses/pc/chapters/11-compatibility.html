この章で分かること

  1. 部品を組み合わせるときの互換性の 5 つの関門（CPU〔Central Processing Unit〕とソケットと起動プログラムの版、メモリ、ストレージ、寸法、電源ユニット）を、順に言える。
  2. メーカーの一次資料（仕様ページ・マニュアル・CPU の対応リスト・メモリの対応表）のどこを見るかと、仕様表の脚注の読み方が分かる。
  3. 確かめた結果を確認表に残し、構成の自動チェックを「参考」にとどめて、一次資料で確かめ直せる。

前提：第03章（マザーボード）と第04章（メモリ）。第05章・第06章・第07章・第08章を読んでいると、確認の項目が分かりやすくなります。

この章の約束

この章は、特定の製品や店を勧めません。部品の寸法や対応の数字は、持ち主の章（第02〜09章）にあります。この章は、それらをどの順で、どの資料で突き合わせるかを扱います。例に出る型番と数字は、すべて架空です。

互換性とは何か、なぜ「関門」に分けるのか

互換性（compatibility）とは、部品どうしが、規格・寸法・電力・ファームウェアの面で一緒に使えることです。「相性が悪い」と言われる不具合の多くは、確かめる項目を一つずつ見ると、原因が説明できます。この講座では、「相性」とは書かず、互換性の関門で考えます。

関門は 5 つです。CPU とソケットと UEFI の版、メモリ、ストレージ、寸法、電源ユニットの順です。UEFI（Unified Extensible Firmware Interface）は、マザーボードに入っていて、電源を入れたときに最初に動くプログラム（ファームウェア）です。詳しくは第17章で扱います。順に確かめると、前の関門で決まったことが、後の関門の条件になります。下の図で、確認の順序を一手ずつたどってください。

図には「不適合のときは選び直し」の分岐があります。1 つの部品を替えると、ほかの関門に影響することがあります。例えば、CPU を替えるとソケットが変わり、マザーボードも、メモリの世代も変わることがあります。選び直したら、確認表を最初から確かめ直します。

確かめる項目と、見る資料

次の表で使う略語を、先にまとめます。DDR（Double Data Rate、メモリの世代の名前。DDR4・DDR5 など）、DIMM（Dual In-line Memory Module、メモリの基板の形）と SO-DIMM（Small Outline DIMM、小さい形の DIMM）、M.2（SSD などを差す小さな拡張カードの形）、SATA（Serial ATA、ストレージをつなぐ規格）、PCIe（PCI Express、拡張スロットの規格）、ATXとSFX（マザーボードや電源ユニットの形の名前）です。

次の表は、5 つの関門ごとの確かめる項目と、見る資料と、よくある見落としです。関門で絞り込めます。各項目の中身（数字や規格の名前）は、右端の章にあります。

一次資料の読み方：CPU の対応リストとメモリの対応表

互換性の確認で、最も大事なのはマザーボードメーカーが公開する 2 つの一覧です。CPU サポートリストは、そのマザーボードが対応する CPU と、必要な UEFI の版の一覧です。QVL（Qualified Vendor List）は、メモリなどについて、メーカーが対応として公開する製品の一覧です。公開の形は、メーカーごとに違います。2 社の例を挙げます。

  • ASUS（ASUSTeK Computer、台湾）の説明では、サポートのダウンロードのページで機種を探し、「CPU / Memory Support」の中の CPU とメモリの一覧を見ます。一覧に載っているモデルには、色の印が付きます（出典：ASUS『[Motherboard] How to query (CPU/memory) QVL List?』、2025 年 7 月 17 日更新の記載）。同じ ASUS の別の記事は、一覧に載っている CPU でも起動しないときは、UEFI の版が古い可能性があるとして、必要な版の確認を案内しています（出典：ASUS『[Motherboard] How to check the motherboard compatibility with the new generation CPU…』、2026 年 9 月 10 日更新の記載）。
  • MSI（Micro-Star International、台湾）の説明では、マザーボードの仕様のページの「DETAIL」の中の「PROCESSOR」に、対応する CPU の系列とソケットが載ります。さらに「See supported processors」の表の「Result」の列に、その CPU に必要な、マザーボードの UEFI（MSI の表記では BIOS〔Basic Input/Output System。UEFI より前のファームウェアの名前で、通称として今も使われる〕）の最小の版が載ります（出典：MSI『[Motherboard] How to Check CPU Support Specifications』、2024 年 12 月 4 日更新の記載）。

この 2 社の例は、公開の形が違うことを見るためのもので、どちらが良いかの比較ではありません。実際には、買うマザーボードの仕様のページと、サポートのページを自分で開いて、この 2 つの一覧の場所を探すことが、最初の作業になります。

なお、QVL に載っていることは、メーカーが確認した手がかりですが、動作の保証ではありません。ASUS の同じ記事も、載っている製品でも、安定性や互換性の問題が起きることがあると書いています。載っていないメモリは、「そのメーカーの一覧には無い」という意味です。使えないと決まるわけではありませんが、確認は取れていません。世代・形・速度を仕様で確かめ、不安定なときは、一覧にあるメモリへ替えます。

仕様表の脚注の読み方

仕様表の中で、最も見落とされるのが脚注（specification footnote）です。表の本体には「M.2 スロット 3 つ、SATA 端子 6 つ」と書いてあっても、脚注に「M.2 を差すと、SATA 端子の一部が使えない」と書いてあることがあります。脚注は、条件と、影響を受けるものと、影響の 3 つに分けると読めます。次の図は、架空のマザーボードの脚注を、3 つに分けた例です。

脚注を読むときの原則は 3 つです。第一に、表の本体より先に脚注を読む。第二に、自分の構成が「条件」に当たるかを確かめる。第三に、当たるなら、影響を受けるものを、自分が使うかを確かめる。使わない端子なら、影響は問題になりません。

UEFI の版で新しい CPU に対応する場合

CPU がソケットに合い、対応リストにも載っていても、マザーボードに入っている UEFI の版が古いと、起動しないことがあります。その場合、古い版を新しい版に更新する必要があります。更新のためだけに、対応する別の CPU を用意するのは大変です。そこで、CPU を載せなくても、UEFI を更新できる機能を持つマザーボードがあります。呼称は、メーカーごとに違います。

部品どうしの干渉

仕様の数字を比べるだけでは、見つからない問題があります。部品どうしの干渉（クリアランス、clearance）です。例えば、次のようなものです。

  • メモリの高さと CPU クーラー：背の高いメモリが、クーラーのファンやフィンに当たる。
  • M.2 のヒートシンクとグラフィックスカード：カードの下のスロットに付けたヒートシンクが、カードに当たる。厚いカードが、下のスロットを覆うこともある。
  • ケーブルの取り回し：電源ユニットのケーブルの曲がりに余裕がなく、側板が閉まらない。
  • ラジエータの位置：ケースの天面に付けると、メモリやマザーボードの上の部品に当たる。

こうした干渉は、マニュアルの図と寸法の表で確かめます。組み立ての途中の確認は、第15章と第16章で扱います。

構成の自動チェックの扱い

部品を選ぶと、組み合わせの適否を表示する自動チェックのサービスがあります。便利な参考ですが、この講座は特定のサービスを勧めません。扱いの原則は次のとおりです。

  • 自動チェックの結果は、参考にとどめる。適合と表示されても、確認表の「資料」にはならない。
  • 最終の判断は、メーカーの一次資料（仕様ページ、マニュアル、CPU サポートリスト、QVL）で確かめる。
  • 自動チェックと一次資料が食い違ったら、一次資料を優先し、食い違った点を確認表に書く。

つまずきやすい点

ソケットが同じでも、動くとは限りません。UEFI の版が足りないと、CPU を認識しないことがあります。ソケットの一致は、関門 1 の最初の項目にすぎません。

「対応」と「推奨」を混ぜないこと。一覧に載っていることと、自分の使い方で十分に動くことは、別の話です。

仕様表の数字だけで決めないこと。脚注と、部品どうしの干渉は、数字の表に出ません。

確認表の資料に、通販の商品説明や口コミを書かないこと。確認表の資料は、メーカーの個別のページにします。
