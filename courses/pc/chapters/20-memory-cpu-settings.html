この章で分かること

  1. 既定の設定と、メーカーが用意したメモリのプロファイル・電力の設定が、何を変えるかを説明できる。
  2. 設定を変えた後に、安定性を確かめ、変更前の状態へ戻せる。
  3. 電圧や倍率を手で変える設定を、この講座で扱わない理由を言える。

前提：第04章（メモリ）、第17章（最初の起動と設定）。あるとよい：第02章（電力の指標）、第19章（負荷試験）。

この章の扱い（定格と保証）

この章は、メーカーが用意した設定の範囲の説明です。電圧や倍率を手で変えて定格を超える設定は、部品の故障や寿命の短縮につながり、保証の対象外になるおそれがあるため、この講座では手順を扱いません。メーカーが用意したプロファイルや機能でも、保証の扱いはメーカーごとに違います。各社の保証規定で確かめてください。

既定の設定は、誰が決めているか

既定の設定（default settings）は、部品を出荷したときの設定です。組み立てた直後の PC は、この設定で動きます。既定の設定は、1 人が決めているのではありません。3 者が重なっています。

1 つ目は、メモリの規格団体です。JEDEC（JEDEC Solid State Technology Association）が、メモリの標準の速度を定めています。値は第04章で扱います。2 つ目は、CPU（Central Processing Unit）のメーカーです。CPU の電力などの既定を、製品ごとに定めます。指標の定義は第02章です。3 つ目は、マザーボードのメーカーです。UEFI（Unified Extensible Firmware Interface）の設定画面（製品や資料では BIOS（Basic Input/Output System）と表示されることがあります）に、出荷時の設定を入れます。

注意したいのは、3 つ目が 2 つ目と同じとは限らないことです。Intel（米国）の社員は、2024 年 6 月の案内で、13 世代・14 世代の Core の CPU（型番の接尾辞が K・KF・KS のもの）で、不安定の報告が出たと述べました。不安定に関わる要因の一つとして、以前の設定による CPU への高い電圧を確認した、と書いています。Intel は、自社の既定の電力供給のプロファイル（Intel の呼称：Intel Default Settings）を勧め、マザーボードのメーカーのサイトで、最新の UEFI を確かめるよう案内しています（出典：Intel『June 2024 Guidance regarding Intel Core 13th and 14th Gen K/KF/KS instability reports』、2024 年 6 月 18 日投稿）。このページには、同年 9 月 25 日付で、より新しい Intel の投稿への案内が付いています。その後の説明は、新しい投稿で確かめます。この案内の対象は、その世代の CPU です。他の CPU に、そのまま当てはまると決めてはいけません。

メモリのプロファイル

メモリのプロファイル（memory profile）は、メモリに記録された、標準より高い速度・タイミング・電圧の組です。UEFI の設定画面で選ぶと、メモリが標準とは別の設定で動きます。呼称は企業ごとに違い、Intel では XMP（Extreme Memory Profile）、AMD（米国）では EXPO（Extended Profiles for Overclocking）です。

各社の資料は、プロファイルを次のように説明しています。Intel は、XMP を、標準の設定を超えた、より高い速度で動かす設定と書き、速度・タイミング・電圧の組だとしています。保証については、Intel の仕様の外で周波数や電圧を変えると、「may void the processor warranty」（プロセッサの保証が無効になることがある）と書いています（出典：Intel『Intel® XMP (Extreme Memory Profile) RAM Overclocking』、2026 年 4 月更新）。AMD は、EXPO を、主に DDR5（Double Data Rate 5 SDRAM）のメモリ向けの、メモリのオーバークロックの支援と書いています。対象は、ソケット（Socket AM5。名前は第03章）の Ryzen です。脚注では、AMD の公表した仕様の外で動かすと、AMD のハードウェアやソフトウェアで有効にしても、AMD 製品の保証が無効になる、と書いています（出典：AMD『AMD EXPO™ Technology for AMD Ryzen™ Processors for Socket AM5』、2026 年 5 月更新）。

この 2 社の書き方は、同じではありません。Intel は「無効になることがある」、AMD は「無効になる」と書いています。1 社の記述を、他の会社に広げてはいけません。メモリのメーカー、マザーボードのメーカー、販売店の保証規定は、別に確かめます（保証の仕組みは第13章）。

プロファイルが使えるかは、マザーボードの対応にも左右されます。Intel は、マザーボードが XMP に対応している必要があり、確認はマザーボードのメーカーに、と案内しています。メモリの対応表（Qualified Vendor List, QVL）の見方は第04章、第11章です。

CPU の電力の設定

電力の設定（power settings）は、CPU が使う電力の上限などを決める設定です。CPU のメーカーとマザーボードのメーカーが、選択肢を用意します。名前は各社で違うので、名前だけで中身を決めず、各社の資料で確かめます。

一例が、AMD の資料にあります。AMD の Ryzen Master のリファレンスガイド（2.9、2022 年 4 月）は、省電力の動作モード（資料の呼称：Eco-Mode）を、CPU の消費電力を既定より下げるものと説明しています。対象は 3000 系列の CPU で、マザーボードの対応が要ります。また、Eco-Mode では、Precision Boost Overdrive などの別の制御のモードは使えない、と書いています（出典：AMD『AMD Ryzen Master 2.9 Reference Guide』、2022 年 4 月）。この資料は古い世代の説明です。現行の製品は、製品ページとマザーボードのマニュアルで確かめます。

自動で性能を上げる機能の扱い

CPU には、負荷と温度に応じて、自動で性能を上げる機能があります（第02章）。機能そのものは、CPU のメーカーが仕様として定めたものです。確かめたいのは、マザーボードのメーカーが用意する設定が、CPU のメーカーの既定と同じ範囲かどうかです。

見分け方は 3 つです。誰が用意した設定か（CPU のメーカーか、マザーボードのメーカーか）。公式の資料が、仕様の外や保証について何と書いているか。その資料が、手元の製品に当てはまるか（世代・型番）。3 つのどれかを確かめられないなら、既定のままにします。確かめられた範囲だけを、変えます。

安定性を確かめる

安定性（stability）は、負荷をかけても、固まる・再起動する・エラーが出るなどが起きず、動き続ける性質です。設定を変えた後は、起動できただけで終わりません。負荷試験（第19章）で、温度とエラーを見ながら、決めた時間だけ負荷をかけます。

変更は、一度に 1 つだけにします。メモリのプロファイルと CPU の電力の設定を同時に変えると、不安定になったとき、どちらが原因か分かりません。手順を流れ図にします。

戻し方

戻すために、変える前に 3 つのことをします。設定を記録すること。メモリの速度とタイミング、CPU の電力の設定を、書くか撮影して残します。UEFI の設定画面に、設定の保存の機能がある製品では、保存します。そして、変更した日と内容を残すことです。

戻す操作は、変えた設定を無効にして、記録のとおりにすることです。それでも起動しないときは、設定の初期化の方法をマザーボードのマニュアルで確かめます（第17章）。戻しても不安定なら、設定以外の原因です。第21章の切り分けへ進みます。

この講座で扱わないこと

電圧や倍率を手で変える設定は、この講座では扱いません。一般にオーバークロック（overclocking）と呼ばれる設定です。この講座では「定格を超える設定」と書きます。Intel の資料は、オーバークロックが仕様を超えうること、安定性・安全性・性能・部品の寿命を下げることがあることを述べています。AMD の Ryzen Master のリファレンスガイドの警告は、公表した仕様の外で CPU を使ったことによる損害を、AMD の製品保証の対象外としています。

理由は 4 つです。寿命が縮むおそれがあること。故障のおそれがあること。保証の対象外になるおそれがあること。安全に関わること。手順を読んで試すのではなく、存在と危険を知っておく、という扱いにとどめます。

演習：設定の記録から、範囲と確かめる資料を選ぶ

3 つの設定の記録（すべて架空）を読みます。メーカーが用意した設定か、定格の範囲か、何で確かめるかを決めてから、行を押してください。

つまずきやすい点

「メーカーが用意した設定」は、「定格の範囲」と同じ意味ではありません。各社の資料は、プロファイルを標準の外の設定と説明しています。

起動できたことは、安定の証明ではありません。負荷をかけて、エラーを見ます。

1 社の保証の書き方を、他社に広げてはいけません。Intel と AMD でも、書き方が違います。

記録がないと、戻せません。変える前に、設定を残します。

自分の 1 台でのつながり

組み立てた直後（第17章・第19章）は、既定の設定のまま、温度と安定性の基準を記録します。そのうえで、プロファイルなどを使うかを、各社の保証の記述を読んで決めます。使うなら、1 つずつ変え、記録し、負荷試験をし、戻せる状態にします。
