この章で分かること

  1. 部品を取り付ける順序と、その順序にする理由（外で付けられる物を先に、狭くなる前に、重い物は後に）を説明できる。
  2. 演算の部品（CPU〔Central Processing Unit〕）、メモリ、小型の記憶装置（M.2 規格の SSD〔Solid State Drive〕）、クーラー、ケースへの固定、電源ユニット、グラフィックスカード、ドライブについて、確かめる点とよくある失敗を挙げられる。
  3. 最小構成で起動を確かめるかどうかを、マニュアルの記述で判断する考え方を説明できる。

前提：第03章（マザーボードと規格）、第14章（作業の準備と静電気対策）。第04章（メモリ）、第05章（ストレージ）、第08章（ケースと冷却）を読んでいると、確かめる点が分かりやすくなります。

この章の扱い（静電気）

静電気は、気づかないうちに部品を壊すことがあります。部品は使う直前まで帯電防止の袋に入れておき、端子や部品の面に触れず、縁を持ってください。具体の対策は、各部品のマニュアルの指示に従ってください。

この章の扱い（けがの防止）

ケースの金属の縁や、重い部品（グラフィックスカード、クーラー、電源ユニット）で、けがをするおそれがあります。重い部品は両手で支え、回っているファンに指や物を入れないでください。

この章の扱い（液冷）

液冷のクーラーは、液が漏れると部品の故障や感電のおそれがあります。取り付けと点検はメーカーのマニュアルに従い、配管やポンプを分解しないでください。漏れに気づいたら、すぐに電源を切り、電源ケーブルを抜いてください。部品を自分で組み合わせる本格的な液冷は、この講座では仕組みの紹介だけにとどめます。

この章の使い方

この章の順序と確かめる点は、一般的な例です。各部品のマニュアルが優先です。取り付けの作業は、PC の電源を切り、電源ケーブルを抜いてから行います（第14章）。この章は、作業の手順書の代わりになりません。

この章で「公開情報で確認できた範囲」

取り付けの記述は、マザーボードメーカー 2 社のマニュアル（ASUS〔ASUSTeK Computer、台湾〕の『Motherboard Installation Guide』V9、2026 年 1 月。MSI〔Micro-Star International、台湾〕の『PRO H610M-A DDR4 User Guide』v2.0、2025 年 5 月）、Intel（米国）の CPU の取り付けの記事（古い世代のソケットが対象）、CPU クーラーのメーカー 1 社（Noctua、オーストリア）のマニュアルで確かめました。どれも 1 つの製品群の記述です。もう 1 社の CPU メーカーの取り付けの公式の説明は、確認できませんでした。

順序の考え方

取り付けの順序は、3 つの考え方で決まります。ケースの外で付けられる物を先に付ける。ケースの中が狭くなる前に付ける。重い物は後に付ける。マザーボードは、ケースに入れる前なら、平らな所に置けて、手も工具も入りやすいからです。ただし、マニュアルが違う順序を指示していれば、それに従います。

この章の図に出てくる略語を、先に整理します。CPU（Central Processing Unit）、SSD（Solid State Drive）、HDD（Hard Disk Drive）、M.2（SSD などを差す口と形の規格。第05章）、I/O（Input/Output。入出力）パネル、PCIe（PCI Express。拡張カードを差す規格。第03章）、TIM（Thermal Interface Material。熱を伝える材料。第08章）です。

図は、主経路を番号の順にたどります。途中の分岐は、「最小構成で起動を確かめる」場合と、起動できなかったときの行き先（第21章）です。

どの作業も、PC の電源を切り、電源ケーブルを抜いた状態で行います。組み立ての途中で電源を入れてよいのは、マニュアルが認めているときだけです。MSI のユーザーガイドは、取り付けが終わる前に起動しないよう書き、ねじや金属片が残っていないかを、起動の前に確かめるよう書いています（出典：MSI『PRO H610M-A DDR4 User Guide』v2.0、2025 年 5 月）。

CPU を付ける

CPU の取り付けで、確かめることは 3 つです。向きの印、ピンや接点に触れないこと、力をかけないことです。

  • 向き：ASUS のガイドは、CPU の三角の印とソケットの切り欠きを合わせるよう書き、CPU は 1 つの向きにしか入らないと書いています。
  • 力をかけない：ASUS のガイドは、入らないときに押し込まないよう書き、押し込むとピンが曲がるおそれがあると書いています。一部のソケットでは、固定の前にレバーの保護具を外すこと、レバーを勢いよく戻さないことも書いています（出典：ASUS『Motherboard Installation Guide』V9）。
  • 持ち方と接点：Intel の記事は、CPU を縁で持ち、ソケットの接点と CPU の裏面に触れず、傾けたり滑らせたりせずにまっすぐ下ろすよう書いています。ソケットの保護カバーは、外して保管し、CPU を外すときに戻すよう書いています（出典：Intel『How to Install the LGA115x and LGA1200 Processor into the Socket』、2025 年に最終確認）。MSI のユーザーガイドは、ボードを返品するときのために、保護カバーを保管するよう書いています（出典：MSI『PRO H610M-A DDR4 User Guide』v2.0）。

ソケットの形（ピンがソケット側にある形か、CPU 側にある形か）と、固定の金具は、ソケットの種類で違います（第03章）。マザーボードと CPU のマニュアルで確かめます。

メモリを付ける

メモリは、指定のスロットに、切り欠きの向きを合わせて、奥まで差します。ASUS のガイドは、メモリの切り欠きの位置が世代で違うので、別の世代のメモリは入らないと書いています。MSI のユーザーガイドは、2 つのチャネルで動かすときに、同じ種類・同じ数・同じ密度のメモリを使うよう書いています。どのスロットに何枚差すかは、マザーボードのマニュアルで確かめます（第04章）。

差し込みが浅いと、メモリが認識されないことがあります。ASUS の Q-LED（ASUS の呼称。マザーボードの診断用の表示灯）の記事は、メモリの表示灯が点くときに、奥まで差されているか、マニュアルのスロットの配置どおりか、1 枚ずつ試すか、を確かめるよう案内しています（出典：ASUS『[Motherboard] ASUS motherboard troubleshooting via Q-LED indicators』、2026 年 4 月更新）。

M.2 の SSD を付ける

M.2 の SSD は、スロットの選び方、固定、ヒートシンクの保護フィルムの 3 点を確かめます。

  • スロットの選び方：スロットによって、使える速度や、一緒に使えない接続が違います（第03章）。どのスロットに付けるかは、マザーボードのマニュアルで確かめます。
  • 固定：ASUS のガイドは、ねじや留め具（ASUS の呼称で Q-Latch・Q-Slide）で固定し、長さに合う位置のスタンドオフを使うと書いています。製品によっては、ヒートシンクを先に外します。MSI のユーザーガイドは、SSD の長さに合うスタンドオフを付け、付属のねじで固定するよう書いています。
  • 保護フィルム：ASUS のガイドは、ヒートシンクの熱を伝えるパッドの保護フィルムを剥がすよう書いています。フィルムが残ると、熱が伝わりにくくなります。パッドが傷んだときの交換品の指定も書かれています。

固定が甘いと、起動するドライブとして認識されないことがあります。ASUS の Q-LED の記事は、起動デバイスの表示灯が点くときに、M.2 の SSD を差し直し、ねじが締まっているかを確かめるよう案内しています。

CPU クーラーを付ける

CPU クーラーは、保護カバー、TIM、取り付け金具、ファンの配線先、他の部品との干渉を確かめます。Noctua のマニュアルは、次の点を書いています（出典：Noctua『NH-U12S Installation Manual』、版・日付の記載なし）。

  • ヒートシンクの底の保護カバーを、CPU に固定する前に外す。
  • ソケットごとに、TIM の塗り方（点の数と大きさ）が違う。多すぎると冷えにくくなる。CPU に前の TIM が残っていれば、先に拭き取る。
  • ケースにマザーボードの裏側の開口がなければ、背面の金具（バックプレート）を付けるために、先にマザーボードを外す。
  • ファンは、マザーボードの CPU 用のファンのヘッダーにつなぐ（第16章）。
  • クーラーとファンの金具が、グラフィックスカードや他の部品に触れないか確かめる。メモリとの干渉の寸法は、メーカーの互換性の資料で確かめる。

ASUS のガイドも、TIM が付いていないクーラーには塗ること、指で広げないこと、クーラーとマザーボードの互換性を確かめることを書いています。TIM そのものの種類と役割は第08章、寸法の確認は第11章です。

クーラーを、ケースに入れる前に付けるか、入れた後に付けるかは、製品とケースで違います。下の表で、考え方を整理します。

一体型液冷クーラー（ポンプ・配管・ラジエータが組み上がった液冷のクーラー。第08章）は、ラジエータの置き場と向きを、クーラーとケースのマニュアルで確かめます。この講座は、具体の配置を指示しません。配管やポンプは分解しません。

I/O パネルとスタンドオフ、ケースへの固定

I/O パネル（I/O shield）は、ケースの背面の、マザーボードの端子が出る部分にはめる板です。ASUS のガイドは、マザーボードに付いていないときに付けるよう書いています。マザーボードをケースに入れる前に付けるのは、固定の前に、背面の端子とパネルの穴を合わせる必要があるからです。

スタンドオフ（standoff）は、ケースの取り付け面に付けて、マザーボードを浮かせて支える金具です。マザーボードのねじ穴の位置に合わせて付けます。MSI のユーザーガイドは、基板の裏に「付けない」の印がある位置には、スタンドオフを付けないよう書いています。印の意味と理由は、マザーボードのマニュアルで確かめます。

マザーボードは、背面の端子を合わせて入れ、付属のねじで固定します。ASUS のガイドは、締めすぎないよう書いています。ねじや金属片を、ケースの中に残してはいけません。

電源ユニット・グラフィックスカード・ドライブ

電源ユニットは、ケースの所定の位置に固定します。向きと固定の位置は、ケースと電源ユニットのマニュアルに従います。重いので、両手で支えます。電源ユニットは、分解しません。

グラフィックスカードは、PCIe のスロットに奥まで差し、背面のブラケットで固定します。奥まで差さっていないと、画面が出ないことがあります。重いカードは、たわむことがあり、支えを使う製品もあります（第06章）。補助電源の配線は第16章です。

ドライブ（SSD・HDD）は、ケースの取り付け位置に固定します。ケーブルが届くかを確かめてから付けます。

最小構成で起動を確かめるか

最小構成（minimal configuration）は、起動を確かめるために、必要な最少の部品だけをつないだ構成です。組み立ての途中で起動を確かめると、不具合の原因が部品の少ない段階で見つかりやすくなります。一方で、MSI のユーザーガイドは、取り付けが終わる前に起動しないよう書いています。

どちらに従うかは、マザーボードのマニュアルが認めているかどうかで決めます。認めていないときは、取り付けと配線を終えてから、第17章へ進みます。認めている場合でも、通電中に部品の取り付けや取り外しをしてはいけません。確かめたら、電源を切り、電源ケーブルを抜いてから、次の作業へ戻ります。起動できないときは、第21章の切り分けへ進みます。

部品ごとの確かめる点とよくある失敗

演習：架空の部品一式で、取り付けの順を並べる

利用者 A さん（架空。出典：架空、見本のため）は、次の作業をします。ケースは、マザーボードの裏側の開口がなく、CPU クーラーはバックプレートで付けるタイプです。I/O パネルは別体です。各部品のマニュアルは、この章の順序と違う指示をしていないものとします。次の 9 つの作業を、取り付ける順に並べてください（下の並びは、答えの順ではありません）。

  1. (ア) 電源ユニットをケースに固定する
  2. (イ) グラフィックスカードを PCIe のスロットに差す
  3. (ウ) CPU クーラーを付ける
  4. (エ) ドライブを固定する
  5. (オ) メモリを差す
  6. (カ) マザーボードをケースに固定する
  7. (キ) M.2 の SSD を付ける
  8. (ク) CPU をソケットに付ける
  9. (ケ) I/O パネルをケースの背面にはめる
答えを見る

順序の一例は、(ク) CPU → (オ) メモリ → (キ) M.2 の SSD → (ウ) CPU クーラー → (ケ) I/O パネル → (カ) マザーボードをケースへ → (ア) 電源ユニット → (イ) グラフィックスカード → (エ) ドライブです。この後が、第16章の配線です。

理由：CPU・メモリ・M.2 の SSD・CPU クーラーは、ケースの外で、手が入りやすいうちに付けます。この例のケースは、マザーボードの裏側の開口がないので、クーラーのバックプレートは、マザーボードがケースに入る前に付ける必要があります。I/O パネルは、マザーボードを入れる前に付けます。重い電源ユニットとグラフィックスカードは、後です。

電源ユニット・グラフィックスカード・ドライブの間の順序は、ケースの作りによって入れ替わることがあります。ケースのマニュアルで確かめてください。

つまずきやすい点

入らないときに、力で押し込まないでください。CPU もメモリも、向きと位置が合っていないと入りません。入らないときは、向きの印と切り欠き、スロットの位置を確かめます。

「付けない」の印の位置に、スタンドオフを付けないでください。MSI のユーザーガイドが禁止している位置です。ケースのスタンドオフが最初から付いていて、位置が合わないときも、マニュアルで確かめます。

保護フィルムと保護カバーを、剥がし忘れないでください。M.2 のヒートシンクの保護フィルムも、CPU クーラーの底の保護カバーも、剥がし忘れると、熱が伝わりません。

自分の 1 台でのつながり

選ぶ段階（第11章）で確かめた寸法とソケットが、ここでの取り付けの前提です。組みながら、気づいた点（ねじの位置、ケーブルの長さ、向き）を、写真と一緒にメモしておくと、増設と交換（第22章）や、不具合の切り分け（第21章）で役立ちます。
