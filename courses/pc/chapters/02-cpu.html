この章で分かること

  1. CPU（Central Processing Unit）の仕様表にあるコア・スレッド・クロック周波数・キャッシュが、それぞれ何を表すかを説明できる。
  2. 内蔵グラフィックスの有無が型番の接尾辞に表れること、ない製品ではグラフィックスカードが必須になることを、仕様ページで確かめられる。
  3. TDP（Thermal Design Power）などの電力の指標は、企業ごとに名前も定義も違い、実際の消費電力そのものではないことを理解し、値の前に名前を確かめる習慣を持てる。

前提：第01章（PC の全体像）。

CPU は、命令を実行する部品

CPU（Central Processing Unit）は、プログラムの命令を読んで実行する部品です。中には、コア（core）、キャッシュ（cache）などが入っています。PC の中で、もっとも多くの種類の仕事を受け持ちます（一般知識）。

この章では、仕様表の用語を 4 つ押さえます。コアとスレッド、クロック周波数、キャッシュ、そして内蔵グラフィックスです。最後に、読み違えやすい電力の指標を扱います。企業は、Intel（米国）と AMD（Advanced Micro Devices。米国）の製品ページの値を例にします。例であり、推奨ではありません。

コアとスレッド

コアは、CPU の中で命令を実行する単位です。コアが受け持つ命令の流れを、スレッド（thread）と呼びます。1 つのコアが 2 つのスレッドを同時に扱う方式があり、その場合、スレッドの数はコアの数の 2 倍になります。

実例を見ます。AMD の Ryzen 5 9600X の製品ページは、6 コア・12 スレッドと書いています。Intel の Core Ultra 7 265K の製品ページは、20 コア・20 スレッドで、数が同じです。数字だけでは、スレッドの扱い方は分かりません。仕様表の「コア」と「スレッド」の 2 つの欄を、両方読みます。

表の値は、各社の製品ページの値です。値の名前は企業ごとに違うので、行ごとに名前を書きました。企業の間で、優劣は示しません。ソケットの名前（FCLGA1851・AM5）は、第03章で基板との対応を扱います。

ハイブリッド構成：2 種類のコア

Intel の Core Ultra は、性能を重視したコアと、効率を重視したコアを、1 つの CPU に組み合わせています。これをハイブリッド構成（hybrid architecture）と呼びます。Intel の呼称は、Performance-core（P コア）と Efficient-core（E コア）です。

どのコアにどの処理を任せるかは、OS（Operating System）が関わります。Intel は、この割り当てを助ける仕組みを Thread Director と呼んでいます。AMD の確認した製品ページには、コアの種類の別が書かれていません。他社の機能を、同じものと書くのは避けます。

クロック周波数と、自動で上がる速さ

クロック周波数（clock frequency）は、CPU が処理を進める拍子の速さです。単位は GHz（ギガヘルツ）で、1 秒間に拍子が何十億回あるかを表します。

多くの CPU には、基本の値のほかに、条件が良いときに自動で高くなる仕組みがあります。Intel は Turbo Boost、AMD は Precision Boost と呼びます。Intel のページは、この上昇が処理の内容と熱の余裕で決まると書いています。AMD のページは、温度・ソケットの電力・電流の上限の範囲で上がると書いています。つまり、最大の値は、いつも出るとは限りません。クーラーが弱いと、上がる幅が小さくなります。

キャッシュ：CPU の近くにある小さくて速い記憶

キャッシュは、よく使うデータの写しを置く、小さくて速い記憶です。CPU の中や近くにあります。メインメモリ（第04章）より小さく、速い記憶です。AMD の Ryzen 5 9600X の製品ページは、L2 キャッシュを 6 MB、L3 キャッシュを 32 MB と書いています。L は階層（level）の頭文字で、数字が小さいほど、コアの近くにあります（一般知識）。

キャッシュの量が多いほど速い、とは限りません。使う処理の内容で、効き方が変わります。仕様表の数字は、同じ企業の同じ系列の中で、読み方を揃えて確かめます。

内蔵グラフィックス：映像を作る部分

内蔵グラフィックス（integrated graphics）は、CPU の中に入っている、映像を作る部分です。あれば、グラフィックスカード（第06章）がなくても、基板の映像端子から画面に映せます。

ない製品もあります。Intel は、型番の接尾辞 F を「Requires discrete graphics」（独立したグラフィックスが必要）と説明しています。AMD の Ryzen 5 9500F の製品ページは、Graphics Model の欄に「Discrete Graphics Card Required」と書いています。この種の CPU で組むと、グラフィックスカードがないかぎり、画面が映りません。選ぶ前に、必ず仕様ページの欄を読みます。

内蔵グラフィックスの有無は、型番の字だけでは決めつけられません。AMD の Ryzen 5 9500F では、ページの欄が根拠です。製品ごとに、ページで確かめます。

型番の読み方

型番には、系列・階層・世代・接尾辞が入っています。Intel は、命名の規則を公式のページに載せています。AMD は、確認した範囲では、命名の規則を説明する公式のページを見つけられませんでした。そのため、AMD の読み方は、製品ページから読める範囲にとどめます。

型番の数字が大きいほど性能が高い、とは限りません。同じ世代の中でも、階層や接尾辞で機能が違います。必ず、仕様ページで確かめます。

NPU：AI の計算のための部分

NPU（Neural Processing Unit）は、人工知能（AI）の計算を、少ない電力で行うための専用の部分です。載せた製品の公開仕様に、性能が TOPS（Tera Operations Per Second。1 秒あたりに何兆回の演算ができるか）で書かれます。Intel の Core Ultra 7 265K のページは、NPU を「Intel AI Boost」、13 TOPS（Int8）と書いています。AMD の Ryzen AI 7 450G のページは、「Up to 50 TOPS」と書いています。TOPS は、測り方が企業ごとに違うため、企業の間では比べません。活用の話は第25章です。

電力の指標：TDP とその仲間

仕様表には、TDP（Thermal Design Power）に似た欄がよくあります。ところが、名前も定義も企業ごとに違います。Intel の最近の資料は、Processor Base Power（基準の電力）と Maximum Turbo Power（上限の電力）という 2 つの値を載せます。AMD の製品ページは「Default TDP」の欄を載せます。

共通して言えるのは、次の 3 点です。

  • どれも、実際の消費電力そのものではありません。処理の重さと温度で、実際の電力は変わります。
  • 名前が違えば、定義も違います。数字が同じでも、同じ意味とは限りません。
  • 定義の確認は、メーカーの公式の資料で行います。販売店の説明では、定義は確かめられません。

CPU の電力は、マザーボードの電源回路（第03章）と、電源ユニット（第07章）、冷やす部品の選び方に関わります。ただし、「指標が大きい CPU にはこの電源ユニット」のような対応は、この章では書きません。各社の公式の資料で確かめます。

最大の動作温度

製品ページには、最大の動作温度の欄もあります。Intel の Core Ultra 7 265K のページは「Max Operating Temperature」を 105 ℃、AMD の Ryzen 5 9600X のページは「Max. Operating Temperature (Tjmax)」を 95 ℃ と書いています。名前が違うので、数字を企業の間で比べません。この温度を超えて使い続けることは、設計の範囲の外です。ふだんの運転で、この温度に近づくなら、冷却が足りていないしるしです。

この章のしてはいけないこと

CPU の定格（メーカーが公表する動作条件）を超える設定や、冷却を外した状態での運転は、この講座では扱いません。定格を超える設定は、製品の保証の対象外になることがあります。Intel は、クロックや電圧を変えると保証が無効になることがある、と書いています。作業の前には、PC の電源を切り、電源ケーブルを抜きます。

演習：条件に合う CPU を選ぶ

次は、架空の CPU 3 つの仕様表です。利用者 A さんは、グラフィックスカードを使わず、電力の指標の値が小さい CPU を選びたい、と考えています。どれが条件に合うでしょうか。理由も答えてください。

答えを見る

答えは CPU ア です。内蔵グラフィックスがあり、基準の電力も 65 W と小さい値です。CPU イ は 65 W ですが、内蔵グラフィックスがなく、グラフィックスカードが必須です。CPU ウ は、内蔵グラフィックスがありますが、125 W で、もっとも大きい値です。

考え方は、条件を 1 つずつ表に当てはめることです。まず、「必須の条件」（内蔵グラフィックス）で絞り、次に、「小さいほうが良い値」を比べます。（すべて架空の仕様表です。実際の製品では、値の名前と定義も確かめます。）

つまずきやすい点

末尾に F の付く CPU は、映像を出せないことがあります。内蔵グラフィックスがない製品では、グラフィックスカードがないと、画面が映りません。買う前に、仕様ページの欄を読みます。

TDP の数字は、消費電力ではありません。メーカーが設計のために決めた値です。Intel の資料では、短い間は、基準の値を超える電力が使われます。名前が違えば定義も違うので、企業の間で数字を比べません。

コアの数が多い CPU が、いつも速いわけではありません。スレッドの数や、クロック周波数、処理の内容でも、結果は変わります。

クロックの最大の値は、いつも出るとは限りません。温度や電力の余裕で、上がる幅が変わります。

自分の 1 台でのつながり

選ぶとき：用途を決め、内蔵グラフィックスの有無と、コアとスレッドの数を、仕様ページで確かめます。組むとき：CPU の電力の指標の「名前」を、基板と冷やす部品の資料の言葉に揃えて読みます。直すとき：画面が映らない症状では、CPU に内蔵グラフィックスがあるかを、最初に疑います。
