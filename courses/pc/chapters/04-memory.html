この章で分かること

  1. メインメモリの役割と、世代（DDR（Double Data Rate）4・5）の違い、世代の間で互換がないことを説明できる。
  2. 「DDR5-6000」のような表記の数字が、MHz ではなく MT/s（Mega Transfers per second。1 秒あたりの転送の回数）であることを理解し、製品表記を読める。
  3. 2 つのチャネルと、差すスロットの関係を理解し、マニュアルの図から差す位置を選べる。

前提：第02章（CPU）、第03章（マザーボードと規格）。

メインメモリは、作業中のデータを置く場所

メインメモリ（main memory）は、CPU が作業中のデータとプログラムを置く記憶です。電源を切ると、中身は消えます。ストレージ（第05章）より速く、容量は小さいのが普通です（一般知識）。

容量が足りなくなると、OS（Operating System）は、使っていないデータをストレージへ移して、作業を続けようとします。ストレージはメインメモリより遅いので、体感の速さが落ちることがあります（一般知識）。用途に合う容量の考え方は、第10章で扱います。

世代：DDR4 と DDR5

メインメモリの標準は、JEDEC（JEDEC Solid State Technology Association、半導体の標準化団体）が定めています。世代は DDR4 と DDR5 が中心です。

世代が違うと、切り欠きの位置が違い、差せません。Kingston Technology（米国）の資料は、DDR5 は DDR4 のスロットに差せない、と書いています。電圧の標準も違い、DDR4 は 1.2 V、DDR5 は 1.1 V です。世代の違うメモリは、混ぜられません。買う前に、マザーボードの仕様表で、対応する世代を確かめます（第03章）。

DDR5 では、電圧を調整する回路が、メモリのモジュールの上にあります（JEDEC の発表）。そのため、モジュールの中の構成も、DDR4 とは違います。

モジュールの形：DIMM と、新しい形

DIMM（Dual In-line Memory Module）は、メインメモリの DRAM（Dynamic Random Access Memory）チップを載せた、細長い基板です。デスクトップ PC では、この形を使います。小型の機器向けの形は SO-DIMM と呼びます（Kingston の用語集）。

JEDEC は、別の形として、CAMM2（JESD318）を公表しています。DDR5 と LPDDR5・LPDDR5X を対象とする規格です。この講座では、名前と対象だけを扱います。ふだんのデスクトップ PC の自作では、基板の仕様表が対応する形を書いているので、それに合わせます。

速度の表記：MT/s と MHz

「DDR5-6000」の 6000 は、MT/s の値です。1 秒あたりの転送の回数で、MHz（クロック周波数）の値とは別です。Kingston の用語集は「DDR5-4800 または 4800MT/s」と、2 つの書き方を示しています。Micron Technology のページも、MT/s と MHz の違いを説明しています。

この講座では、メモリの速度は MT/s で書きます。「DDR5-6000 は 6000 MHz」とは書きません。CPU のクロック周波数（第02章）とは、別の量です。

もう 1 つの数字がメモリタイミングです。製品表記の「CL30」（CL は CAS Latency の略）などで、応答の待ち時間をクロックの回数で表します。同じ世代と速度の中で比べます。

チャネルと枚数：2 枚のときは、指定の位置に

CPU のメモリコントローラは、メモリへの通り道を、チャネルとして持っています。デスクトップ PC の基板は、2 チャネルで、スロットが 4 本の構成が一般的です。各チャネルに 1 枚ずつ差すと、2 つの通り道が同時に働きます。これをデュアルチャネルと呼びます。

差す位置は、基板のマニュアルの図で決まっています。ASUS（台湾）のサポートの記事は、2 枚のときは DIMM_A2 と DIMM_B2 のスロットに差す、と書いています。ASRock（台湾）のマニュアルは、デュアルチャネルには同じ組のメモリが要り、1 枚や 3 枚では有効にならない、と書いています。位置の名前と決まりは基板で違うので、必ず自分の基板のマニュアルの図で確かめます。

枚数で、対応する速度が変わることもあります。AMD（米国）の Ryzen 5 9600X の製品ページは、メモリの対応を「2x1R/2x2R は DDR5-5600、4x1R/4x2R は DDR5-3600」と書いています。Intel（米国）の Core Ultra 7 265K のページは「DDR5 の 6400 MT/s まで」と書きます。値の名前と数え方は、企業で違います。使う CPU の製品ページと、基板の仕様表で、枚数ごとの値を確かめます。

ECC：誤りを訂正する仕組み

ECC（Error Correcting Code）は、メモリの誤りを訂正する仕組みです。PC では、CPU と基板の対応で決まります。Intel のチップセット（品番 Z890）のページは、ECC メモリへの対応を「No」と書いています。AMD の Ryzen AI 7 450G のページは「Yes (Requires mobo support)」、つまり、基板の対応が要ると書いています。必要かどうかは、用途と、CPU・基板の資料で確かめます。

プロファイルと QVL

メモリには、標準の速度のほかに、メーカーが用意した速い設定の情報（プロファイル）が入っていることがあります。Intel の呼称は XMP（Extreme Memory Profile）、AMD の呼称は EXPO（Extended Profiles for Overclocking）です。Intel の資料は、XMP 2.0 は DDR4、XMP 3.0 は DDR5 向けで、クロックや電圧を変えると保証が無効になることがある、と書いています。設定の詳細は第20章で扱います。

QVL（Qualified Vendor List）は、マザーボードメーカーが公開する、動作を確かめたメモリの一覧です。ASUS の記事は、QVL にあるメモリを使うことを勧めています。載っていない製品が動かないと決まるわけではありませんが、確かめる手がかりになります。

演習：2 枚のときに差すスロットを選ぶ

次は、架空のマザーボード Y のマニュアルの図です。利用者 B さんは、同じ 16 GB のメモリ 2 枚（DDR5）を差します。どのスロットに差せばよいでしょうか。理由も答えてください。

答えを見る

答えは、スロット 2 とスロット 4 です。マニュアルの指定で、スロット 2 は「2 枚のときはここを使う」、スロット 4 は「2 枚のときはここも使う」と書かれています。スロット 2 はチャネル A、スロット 4 はチャネル B なので、各チャネルに 1 枚ずつ差さり、デュアルチャネルになります。スロット 1 と 3 は、4 枚のときだけ使うので、空けます。

考え方は、枚数の指定を表から拾うことです。（すべて架空のマニュアルです。実際の基板では、自分のマニュアルの図に従います。）

つまずきやすい点

世代の違うメモリは、混ぜられません。買う前に、基板の仕様表で DDR4 か DDR5 かを確かめます。

「DDR5-6000」の 6000 は MHz ではありません。MT/s です。製品の間で比べるときも、単位を揃えます。

スロットの数があっても、どこに差してもよいわけではありません。2 枚のときの位置は、マニュアルの図で決まります。

枚数を増やすと、対応する速度が下がる CPU があります。製品ページの枚数ごとの値を読みます。

メモリを差すときは、PC の電源を切り、電源ケーブルを抜いてから行います。スロットの両側の留め具を確かめ、無理に押し込みません。具体の作業は、各部品のマニュアルに従います（第15章）。

自分の 1 台でのつながり

選ぶとき：基板の対応する世代と、CPU の対応する速度を、仕様ページで確かめます。組むとき：2 枚を差す位置を、基板のマニュアルの図で決めます。直すとき：起動しない症状では、メモリがスロットの奥まで入っているかを、まず見ます。
