この章で分かること

  1. メモリ・ストレージ・グラフィックスカード・CPU（Central Processing Unit）・電源ユニットを交換・増設するとき、先に確かめること、作業の流れ、後で確かめることを説明できる。
  2. CPU の交換で、マザーボードのファームウェアを先に更新する理由と、メモリを足すと設定が変わることがある理由を言える。
  3. OS の移行の 2 つの方法（ドライブの複製と新しく導入）と、ライセンスの再認証の考え方を説明できる。

前提：第15章（取り付けの順序）、第16章（配線）。あるとよい：第11章（互換性）、第21章（不具合の切り分け）。

この章の扱い（電気の安全）

この章は、仕組みと注意点の説明で、作業の手順書の代わりにはなりません。部品の取り付け・取り外し・配線・掃除は、PC の電源を切り、電源ケーブルをコンセントから抜いてから行ってください。電源ユニットは分解しないでください。内部には、電源ケーブルを抜いた後も電気がたまっている部品があり、感電のおそれがあります。具体の作業は、各部品のマニュアルに従ってください。

この章の扱い（静電気）

静電気は、気づかないうちに部品を壊すことがあります。部品は使う直前まで帯電防止の袋に入れておき、端子や部品の面に触れず、縁を持ってください。具体の対策は、各部品のマニュアルの指示に従ってください。

この章の扱い（データの消失）

OS の導入、ストレージの初期化・交換・消去では、データが消えることがあります。作業の前に、必要なデータのバックアップ（第24章）を取り、対象のドライブを取り違えないように確かめてください。

この章の扱い（液冷）

液冷のクーラーは、液が漏れると部品の故障や感電のおそれがあります。取り付けと点検はメーカーのマニュアルに従い、配管やポンプを分解しないでください。漏れに気づいたら、すぐに電源を切り、電源ケーブルを抜いてください。部品を自分で組み合わせる本格的な液冷は、この講座では仕組みの紹介だけにとどめます。

交換・増設の前に

増設（upgrade）は、部品を足す、または替えて、性能や容量を上げることです。作業の前に、4 つを済ませます。

1 つ目は、互換性を確かめ直すことです。組み立てたときと同じ 5 つの関門を、新しい部品でもう一度通ります（第11章）。2 つ目は、バックアップです。最新の複製を取り、戻せることを確かめます（第24章）。3 つ目は、UEFI（Unified Extensible Firmware Interface）とドライバの版の確認です。UEFI はマザーボードのファームウェアです。4 つ目は、替えるものを 1 つに絞ることです。一度に複数を替えると、不具合が出たとき、原因を絞れません（第21章）。

一般の手順を、流れ図にします。CPU の交換だけ、UEFI の更新が先に入ります。

具体の作業は、各部品のマニュアルに従ってください。この章は、マニュアルの代わりにはなりません。部品ごとの注意を、表にまとめます。

メモリの増設

メモリを足すときは、まず、マザーボードのマニュアルで、対応する世代と形、スロットの数、枚数ごとの条件を確かめます（第04章）。次に、今のメモリとの組み合わせを考えます。

Kingston Technology（米国）の記事は、できるかぎり、異なる速度・容量のメモリの混在を避けるよう述べています。また、多くの PC は、同じ 2 枚のモジュールを組にするデュアルチャネルを使うと説明しています（出典：Kingston Technology『Upgrading RAM for HP, Dell, Lenovo and Acer Laptops and Desktops』、記事に公表日の記載なし）。同じ仕様のモジュールを複数枚の組にして売るものを、メモリキット（memory kit）と呼びます。同じ製品でも、足りない分を後から買うと、組になりません。

枚数が増えると、使える速度の設定が変わることがあります（第04章）。足した後は、UEFI の設定画面で、容量と速度の設定が想定どおりかを確かめます。メモリのプロファイルを使っていたときは、有効のままかも確かめます（第20章）。

ストレージの増設と入れ替え

ストレージを足すときは、M.2 のスロット（形の規格。第05章）が、別の端子と共有になっていないかを確かめます（第03章）。入れ替えるときは、OS をどう移すかが問題になります。

方法は 2 つあります。ドライブの複製（disk cloning）は、ドライブの内容を、別のドライブへそのまま写します。OS・アプリ・設定を入れ直さずに済みます。新しく導入は、新しいドライブに OS を入れ直し（第18章）、ファイルと設定を戻します。表で比べます。

OS のライセンスの扱いも確かめます。Microsoft（米国）の案内によると、デジタルライセンスは、デバイスのハードウェアに結びつきます。大きな変更の後は、一致するライセンスが見つからず、再認証が要ることがあります。大きな変更の例として、マザーボードの交換が挙げられています。認証のトラブルシューティングを使うには、Microsoft アカウントとの関連付けが要ります。エディション（Home か Pro か）は、同じものにします。プロダクトキーで認証していたときは、同じキーを使います（出典：Microsoft『Reactivating Windows after a hardware change』、2026 年 9 月更新）。ストレージだけを替えたときの扱いは、この案内に書かれていないので、この講座では書きません。認証の仕組みは第18章です。

移行が済むまで、元のドライブのデータは消しません。古いドライブを手放すときは、データを消去します（第24章）。

グラフィックスカードの交換

先に、新しいカードの長さ・厚さ・補助電源のコネクタが、ケースと電源ユニットに合うかを確かめます（第06章、第11章）。電源ユニットの容量も、確かめ直します（第12章）。重いカードは、サポートステーで支えることを考えます（第06章）。

交換した後は、ディスプレイのケーブルを、新しいカードの端子に差し替えます。マザーボードの端子に差したままでは、映像が出ないことがあります（第21章）。ドライバは、新しいカードのメーカーの案内に従って入れます（第18章）。最後に、負荷試験で温度と騒音を確かめ、基準の記録を取り直します（第19章）。

CPU の交換

CPU の交換では、UEFI の更新を先に行います。新しい CPU を付ける前に、マザーボードの UEFI を、その CPU に対応した版へ更新します。AMD（米国）の案内は、マザーボードが新しい Ryzen に対応していないと、PC が起動しないことがあると述べています（出典：AMD『BIOS Updates for AMD Ryzen™ Desktop Systems』、2026 年 8 月更新。資料の表記は BIOS（Basic Input/Output System））。ASUS（ASUSTeK Computer、台湾）の FAQ（Frequently Asked Questions、よくある質問）は、新しい CPU がマザーボードの CPU サポートリストにあるかを確かめ、載っていれば、対応する UEFI の版へ更新する、と順に案内しています（出典：ASUS『How to check the motherboard compatibility with the new generation CPU and troubleshooting of the booting issue?』、2026 年 9 月更新）。

更新に使える古い CPU がなく、起動できないときは、CPU を載せずに UEFI を更新できる機能があるかを確かめます。AMD の案内は、対応するマザーボードでは、USB（Universal Serial Bus）メモリから更新する機能（資料の呼称：USB BIOS Flashback）を挙げています。呼称は各社で違います（第11章）。

クーラーを外したときは、古い TIM（Thermal Interface Material、熱を伝える材料）を拭き取り、新しく塗り直します（第08章）。一体型液冷クーラーを外すときは、配管とポンプを分解しません。交換の後は、UEFI の設定画面で CPU が正しく認識されているかを確かめ、負荷試験で温度を見ます（第17章、第19章）。

電源ユニットの交換

電源ユニットを替えるときは、ケーブルも、すべて新しい電源ユニットのものに替えます。着脱式のケーブルは、ピンの並びが製品で違うことがあります。他の製品のケーブルを混ぜると、部品を壊すおそれがあります（第07章）。容量・コネクタ・寸法も、確かめ直します（第12章、第11章）。

電源ユニットは分解しません。古い電源ユニットを手放すときも同じです。廃棄の制度は第13章で扱います。

外した部品の扱い

外した部品は、すぐ捨てません。新しい部品が不良だったとき、元に戻して確かめるために、動作が確認できるまで保管します。保管は、帯電防止の袋に入れて、端子に触れないようにします（第14章）。譲る・売る・捨てるときは、ストレージのデータを消去します（第24章）。

つまずきやすい点

CPU は、付けてから UEFI を更新するのではありません。先に更新します。古い CPU がなく、起動できないと、更新の方法が限られます。

メモリは、同じ製品でも、後から足すと別の組になります。混在はできるだけ避け、足した後に設定を確かめます。

OS の複製は、ライセンスの再認証を不要にするとは限りません。ハードウェアが大きく変わると、再認証が要ることがあります。

一度に複数を替えない。不具合が出たとき、原因を絞れなくなります。

自分の 1 台でのつながり

替える前に、構成表と確認表（第11章）を更新し、バックアップを取ります。替えた後は、負荷試験と温度の基準の記録を取り直し、保守の記録に残します（第23章）。
