# 金融 3 講座 — 用語と単位と記号の表記ルール（共通版）

対象：A『金利と国債、中央銀行の資金供給』（`rates`）、B『取引所の金利デリバティブ』（`ird`）、C『指数オプション取引』（`idxopt`）。全章担当の必読文書です。各講座の `GLOSSARY-RULES.md` は、この文書との**差分**（講座だけの語の割り当て・例外）だけを書きます。両方にない語・表記は §8 の手順で決めてから使います。設計の共通ルールは `SPEC-COMMON.md`。

## 1. 基本

1. 読者向けの文章は日本語。専門用語は**章ごとの初出**で英語を併記し、2 回目以降は日本語か略語だけにする（§3）。
2. 英語は、当局・取引所・清算機関の文書の綴り（米国式。例：`yield curve`、`central counterparty`、`initial margin`）。
3. 数字は半角。半角の数字・英字と和文の間には半角スペース（「25 bp」「3 か月」「H.4.1 の表」）。章番号は「第04章」と詰める。
4. 範囲は「〜」、並列は「・」、選択肢の区切りは「／」。
5. **当局・取引所の正式な語を優先**する（日銀の「金融市場調節」「資金供給オペレーション」「補完当座預金制度」「基準貸付利率」、財務省の「カレンダーベース市中発行額」、大阪取引所の「取引単位」「限月取引」「呼値の単位」「即時約定可能値幅」、JSCC の「清算参加者」「清算基金」など）。言い換えない。
6. 文体は「です・ます」。読者への呼びかけは「あなた」を使わず、主語を省くか「読者」と書く。
7. **推奨に読める語を使わない**（`SPEC-COMMON.md` §1-2 の禁止語）。

### 2.3 意味の使い分け（3 講座で同じ）

| 語 | 意味 | 混同しない語 |
|---|---|---|
| **金利** | お金を貸し借りするときの、元本に対する利息の割合（年率）。一般の語 | — |
| **利率**（クーポンレート） | 債券の券面に決められた、額面に対する年あたりの利息の割合 | 利回り |

| **政策金利** | 中央銀行が金融政策の手段として誘導・設定する金利。何を指すかは中央銀行ごとに原文で書く（日銀：無担保コールレート〔オーバーナイト物〕の誘導目標、FOMC：フェデラル・ファンド金利の目標の範囲） | 付利の金利、基準貸付利率 |

| **保有資産の縮小** | 中央銀行が、満期が来た債券の再投資を減らす・止めるなどして保有資産を減らすこと（QT と略す報道があるが、初出で「保有資産の縮小（QT と呼ばれることがある）」と書く） | 売却（縮小の方法の 1 つ。区別して書く） |

| **証拠金** | 先物・オプションの取引の履行を確保するために預ける担保 | 手付金・保証金（使わない） |
| **損益図** | 満期の時点の、原資産の価格と損益の関係を描いた図 | 「途中の評価損益の図」（別の図。図の題で区別する） |

2. **略語を見出し・「この章で分かること」の囲みに出さない**（出すときは正式名を併記）。章の題に出る略語（TONA・SOFR・SPX・XSP・SQ・VIX・CCP・PFMI・TWAP・VWAP・H.4.1・H.8・TGA・ON RRP など）は、本文の初出で必ず正式名を書く。

## 5. 数字・単位・記号

1. **金利**：「年 ◯％」。変化は「◯％ポイント」または「◯ bp（ベーシスポイント。1 bp ＝ 0.01％ポイント）」。「0.25％上がった」と書かない（0.25％ポイントか 25 bp）。
2. **価格**：債券は額面 100 円あたりの価格（「100 円につき ◯ 円」）。短期金利先物は「100 − 金利」の形の価格（指数の形。単位を付けない）。
3. **金額**：円は「円・万円・億円・兆円」、ドルは「ドル・百万ドル・十億ドル・兆ドル」（原文が millions of dollars なら「百万ドル」）。統計の値は原文の単位のまま（営業毎旬報告は千円）。為替の換算をしない。
4. **日数と期間**：「3 か月」「1 年」「翌日物（オーバーナイト）」。日数計算の慣行は「実日数/365」「実日数/360」と書く（ACT/365 は `alias`）。
5. **時刻**：日本時間は「◯時◯分（日本時間）」、米国は「午前 ◯ 時 ◯ 分（米東部時間）」。夏時間の扱いは出典の書き方。
6. **記号**：式の記号は各講座 `spec.md` §9.4 の表だけ。r（金利）、t・T（期間・年）、P（価格）、C・P（オプションのコール・プットの価格は C と P。債券価格と紛れる章では債券価格を B と書く。各講座の §9.4）、S（原資産の価格）、K（権利行使価格）、σ（ボラティリティ）。
7. **数値の例は架空**と明記。架空の例でも、実在の水準と紛れる値（例：実在の政策金利と同じ値）は避けてよいが、避けなくてもよい。避けない場合も「架空」と書く。

## 6. 共通の用語（3 講座で同じ見出し語・英語・定義）

各語の**持ち主**（用語集に登録し、本文で定義する章）は 1 つ。ほかの講座でその語を用語集に入れる必要があるときは、**見出し語・英語・`d` を下の表から一字一句写し**、`ch` を自分の章にし、本文で持ち主の章にリンクする（`SPEC-COMMON.md` §6）。`d` は本文の定義と同じにする。

|---|---|---|---|---|
| 金利 | interest rate | 利子率 | お金を貸し借りするときの、元本に対する利息の割合です。ふつう 1 年あたりの割合（年率）で表します。 | A 序1 |
| 年率 | annualized rate | per annum | 期間の長さが違う金利を比べるため、1 年あたりに直した割合です。 | A 01 |
| 単利 | simple interest | — | 利息を元本だけにつける計算です。前の期間の利息には利息がつきません。 | A 序1 |
| 複利 | compound interest | 複利計算 | 前の期間までの利息を元本に加え、その合計に次の利息をつける計算です。 | A 序1 |
| 日数計算 | day count convention | 実日数/365、実日数/360、ACT/365、ACT/360 | 期間の利息を計算するとき、日数を年に直す決まりです。市場・商品ごとに決まっています。 | A 01 |
| ベーシスポイント | basis point | bp、％ポイント | 金利や利回りの変化を表す単位で、0.01％ポイントにあたります。 | A 01 |
| 現在価値 | present value | PV | 将来に受け取るお金を、金利で割り引いて今の価値に直した値です。 | A 02 |
| 割引係数 | discount factor | ディスカウント・ファクター | 将来の 1 円が今いくらにあたるかを表す数です。金利が高いほど、期間が長いほど小さくなります。 | A 02 |
| 最終利回り | yield to maturity | 複利利回り、YTM | 債券を今の価格で買い満期まで持ったとき、受け取る利息と償還金の現在価値の合計が価格に等しくなる割引の金利です。 | A 03 |

| 保有資産の縮小 | balance sheet reduction | QT、量的引き締め、ランオフ | 中央銀行が、満期が来た債券の再投資を減らす・止めるなどして、保有資産を減らすことです。 | A 17 |
| 常設ファシリティ | standing facility | 補完貸付制度、ディスカウント・ウィンドウ、SRF | 金融機関の求めに応じて、決められた条件でいつでも中央銀行が資金を貸す・預かる仕組みです。 | A 18 |
| マネタリーベース | monetary base | 資金供給量 | 中央銀行が供給するお金の量で、日本では日本銀行券の発行高・貨幣の流通高・日銀当座預金の合計です。 | A 25 |
| 先物 | futures | 先物取引 | 将来の決められた日に、決められた価格で売買することを今約束する、取引所の取引です。 | B 序1 |
| 限月 | contract month | 限月取引、満期の月 | 先物・オプションの取引の、満期にあたる月です。 | B 序1 |
| 建玉 | open interest | 未決済建玉 | 取引をした後、反対の売買や最終決済で閉じていない約定です。 | B 序1 |
| 金利スワップ | interest rate swap | IRS、OIS | 同じ元本について、固定の金利と変動の金利など、異なる金利の利息を一定の期間交換する店頭の取引です。 | B 07 |
| 板 | order book | 気配、板情報 | 取引所に出されている、まだ約定していない売りと買いの注文を、価格ごとに並べた一覧です。 | B 08 |

| 見せ玉 | spoofing | スプーフィング、相場操縦 | 約定させる意図のない注文を出して、他の参加者に需給を誤解させる行為です。法令で禁じられる相場操縦にあたるおそれがあります。 | B 13 |
| 清算機関 | central counterparty | CCP、中央清算機関、清算 | 取引の当事者の間に入って、売り手に対しては買い手、買い手に対しては売り手となり、決済を保証する機関です。 | B 23 |

| 変動証拠金 | variation margin | VM、値洗い差金 | 建玉を毎日の価格で評価し直した損益を、清算機関を通じてやり取りするお金です。 | B 24 |
| 値洗い | mark-to-market | 時価評価 | 建玉を、その日の清算の価格で評価し直すことです。 | B 24 |
| 清算基金 | clearing fund | 保証基金、default fund、guaranty fund | 清算参加者が破綻して証拠金で損失をまかなえないときに備えて、清算参加者が清算機関に預ける資金です。 | B 26 |
| オプション | option | オプション取引 | 決められた期間・日に、決められた価格で原資産を売買する権利の取引です。 | C 序1 |

| プット・オプション | put option | プット、売る権利 | 原資産を権利行使価格で売る権利です。 | C 01 |
| 権利行使価格 | strike price | 行使価格、ストライク | オプションの権利を使ったときに原資産を売買する価格です。 | C 01 |
| オプション価格 | option premium | プレミアム | オプションの権利の値段で、買い手が売り手に払います。 | C 01 |

| 本質価値 | intrinsic value | — | いま権利を使ったとしたときに得られる価値で、マイナスにはなりません。 | C 07 |
| 時間価値 | time value | — | オプション価格のうち本質価値を超える部分で、満期までに原資産の価格が動く可能性の価値です。 | C 07 |
| ボラティリティ | volatility | 変動率、ヒストリカル・ボラティリティ | 価格の変動の大きさを、年率の割合で表した値です。 | C 09 |
| インプライド・ボラティリティ | implied volatility | IV | 市場のオプション価格から、価格のモデルを逆に解いて求めたボラティリティです。 | C 11 |
| 特別清算数値 | Special Quotation | SQ、SQ 値 | 大阪取引所の指数先物・指数オプションの最終決済に使う値で、取引最終日の翌営業日の構成銘柄の始値などから算出されます。 | C 05 |
