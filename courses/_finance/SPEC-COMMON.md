## 1. 内容の決まり（3 講座共通・変えない）

1. **教育目的であり、投資助言ではない**。売買の推奨、銘柄・商品・戦略の勧め、相場（金利・価格・指数・ボラティリティ）の予測をしない。各講座の入口（`hero.notice`）と、§3 の「投資」の定型の注意書きを置く章に、その旨を書く。
2. **禁止する記述の形**（自己点検で機械的に探す。§5-7）：「こう取引すれば儲かる」「〜すると有利」「おすすめ」「勝率」「必勝」「利益が出やすい」「狙い目」「買い時・売り時」「〜が割安・割高」（理論価格との差の仕組みを説明する場面の「理論価格より高い・低い」は可）。損益図や数値例で「利益」と書くときは、必ず同じ図・同じ段落に「損失」の側と、損失が限定されない場合はそのことを書く。
3. **アルゴリズムは種類と仕組みの説明にとどめる**。実装の手順・コード・パラメータの値・発注の条件式・遅延を縮める具体的な手段は書かない。**不公正取引につながる手法**（見せ玉〔spoofing〕、レイヤリング、仮装売買、馴合売買、終値の関与、相場の固定、風説の流布、注文の大量の取消による板の撹乱など）は、「**規制で禁じられている行為**」として、規制の条文・当局の説明・取引所の規則の名前と、なぜ禁じられるか（価格形成をゆがめる仕組み）だけを書く。手口の詳しい再現・見分けられにくくする方法は書かない。
4. **公開情報だけ**を使う（当局・中央銀行・財務省・取引所・清算機関・国際機関・基準の運営者の公式ページ、法令の条文、教科書的な一般知識）。報道・まとめ・個人のブログ・動画・有料データの非公開部分を根拠にしない。証券会社の告知は、取引所・清算機関の一次資料が見つからないときだけ「△」で使う（§2.1）。
5. **数字には出典・時点・条件を付ける**（§2.3 の書式）。政策金利・バランスシートの残高・発行額・取引量・証拠金の水準・商品の仕様など、変わる数字は「執筆時点（YYYY 年 M 月 D 日）」と断る。**変わりやすい数字を確認問題・総合テストの正答にしない**。
6. **制度は変わる**。制度・商品・規則に触れる段落は、最初の文で**国・地域と「いつ時点の制度か」**を書く（例：「日本では、2026 年 9 月 18 日の金融政策決定会合の決定（同 24 日から適用）の時点で、…」）。事実確認表の `制度` の行は【国・地域】で始める。
7. **自分で計算した値を事実として書かない**（割合・合計・換算・年率化）。例：Cboe が公表した 0DTE の売買高と SPX の売買高から、割合を自分で計算して書かない。計算は「架空」と明記した値の演習だけで行う。
8. **実在の金融機関・取引参加者の個別の取引・損益・ポジションに触れない**。当局が公表した処分・課徴金の事例は、制度の説明に必要な範囲で、当局の発表の言葉のまま、日付と発表者を付けて引いてよい（個人名は書かない）。
9. **作者の名前・個人名・ペンネーム・ハンドル名・メールアドレスを書かない**。フッターは「© TTJ」だけ（基盤が検査する）。演習の人物・会社は必ず架空（「銀行 A」「取引参加者 B 社」「投資家 C」）。
10. **正確さが最優先**。確信のない細部は書かず、参照資料を示す。「執筆時に Web で確認する事実」は、書く前に一次資料の個別ページで確認し、確認できたものだけ書く。★の項目は公開の直前にもう一度確かめる。

## 2. 事実確認の書式

### 2.1 事実確認表（全章必須）

発電講義 `spec.md` §8.1 と同じ書式・同じ置き場所（30 行を超えたら `facts/NN-同じ名前.md`）。区分は次のとおり（発電講義の区分のうち `仕様値` を `商品` に、`安全` を外し、`統計` と `市場の規則` を足した）。

| 区分 | 何を書くか | 必須の書き方 |
|---|---|---|
| `発表` | 当局・中央銀行・取引所の発表（年月日・主体） | 日付は原文の日付。決定の日と適用の日を分ける |
| `制度` | 法令・政策の枠組み・オペの種類・準備預金制度・付利など | 【国・地域】で始める。「いつ時点」と「適用の開始日」 |
| `市場の規則` | 取引所・清算機関の規則（立会時間・値幅・サーキットブレーカー・約定の方式・証拠金の方式・破綻処理） | 【取引所名】で始める。規則の版・改正日・施行日 |
| `商品` | 商品の仕様（取引単位・限月・最終決済・行使の型・呼値） | 【取引所名】で始め、**仕様のページの更新日**を書く |
| `統計` | 公表統計の値・定義・公表の頻度と時刻 | 「条件：」に**単位・時点（何日現在・週平均か水曜の値か・月末か平均か）・季節調整の有無・速報か確報か**を書く |
| `市場` | 取引量・建玉・市場規模など | 「条件：」に**定義（枚・想定元本・金額）・期間・主体**を書く |
| `企業` | 取引所・清算機関・指数の算出者などの名前 | 「社名変更：なし／あり（日付と旧名）」 |
| `定義` | 用語・式 | 式は §各講座 9.4 の番号 |
| `一般知識` | 教科書的な内容 | 数値を伴うなら教科書名 |

**一次**：`○` 主体自身の個別ページ／`△` 主体の原文を別のサイトが載せたもの、または取引所の規則を証券会社が告知したもの／`×` 報道・解説・まとめ。高リスクの区分（`発表` `制度` `市場の規則` `商品` `統計`）は `○` だけで書く。`△` しかないときは本文に「（◯◯〔掲載者〕の告知による。取引所の一次資料は確認できず）」と書くか、書かない。

### 2.2 高リスクの事実の確認の仕方（発電講義 §8.2 の 1〜20 を引き継ぎ、21〜30 を足す）

21. **決定日と適用日**：金融政策の決定は「決定の日」と「適用の日（翌営業日など）」が違う。両方を原文の語で書く（例：日銀 2026-09-18 決定、同 09-24 から適用）。
22. **「程度」「〜で推移するよう促す」**：日銀の誘導目標は「◯％程度で推移するよう促す」、FOMC は「目標の範囲（target range）」。言い換えて「◯％に設定」と書かない。
23. **計画と実績**：国債の発行計画（当初・補正後）、買入れの予定額と実績額、減額計画の「予定」と「実績」を区別する。計画の版（当初・補正後・改定）と公表日を書く。
24. **統計の時点の種類**：H.4.1 は水曜の値と週平均がある、営業毎旬報告は「◯日現在」、マネタリーベースは月中平均と月末残高がある、など。**どの時点の値か**を必ず書く。
25. **単位**：営業毎旬報告は千円単位、他の統計は億円・兆円・百万ドル（millions of dollars）など。原文の単位で写し、換算は演習だけ。
26. **日数計算の慣行**：TONA・円の短期金利は実日数/365、SOFR・米ドルの短期金利は実日数/360、が一般的。慣行は出典で確かめ、出典の書き方で書く。
27. **商品の仕様の更新**：取引所の仕様のページは改定される（例：日経225ミニオプションは 2025-05-26 から水曜日に満期の限月の取引を開始）。**仕様のページの更新日**を事実確認表に写す。
28. **規則の方式の変化**：証拠金の計算方式（SPAN → VaR → 期待ショートフォールなど）、約定の方式、システムの世代は変わる。方式の名前は**現行の公式のページの語**で書き、移行の日は一次資料で確かめる。移行の日が確かめられないときは「◯年◯月の時点の公式ページでは◯◯」とだけ書く。
29. **過去の事例**：市場の混乱・破綻処理の事例は、当局・清算機関の公式の報告書の言葉で書く。報道の解説で原因を書かない。
30. **相場の水準を書かない**：本文・図・問に、実在の金利・指数・価格・ボラティリティの**現在の水準**を書くのは、制度の説明に必要なとき（政策金利、付利など）だけ。その場合も時点と出典を付ける。市場の価格（国債の利回り・先物の価格・指数・VIX の値）は書かない（架空の値で示す）。

## 5. 確認問題・自己点検・参照資料（3 講座共通）

1. **確認問題**は各章ちょうど 3 問・各 4 択。正答の添字は第 NN 章の k 問目で `a = (NN + k − 1) mod 4`。序章 In（n＝1, 2）の k 問目は `a = (n + k) mod 4`。総合テストは本編の章で `a = (NN + 2) mod 4`（2 問の章の 2 問目は `(NN + 3) mod 4`）、付録の横断問題は i 問目（0 始まり）で `a = i mod 4`。

### 7.A `scale` の金額の単位（円・ドル）

項目の `unit` に、円は `円・万円・億円・兆円`、ドルは `ドル・百万ドル・十億ドル・兆ドル` を書く（`value`・`range` で使える。`from` は電力だけ）。**1 つの `scale` に円とドルを混ぜるとビルドがエラー**（為替の換算はしない）。目盛り・探る値・計算の文は、円・ドルの単位に自動で付け替わる。

```js
CN.add('scale', 'c01-money', {
  title: '金額の大きさ', base: 'salary', initial: 'gdp',
  sources: [{ n: 1, issuer: '発行元', title: '資料名', date: '2026-11' }],
  groups: [{ key: 'a', label: '個人' }, { key: 'b', label: '国' }],
  stages: [{ key: 'all', label: '全体（1 円〜1 京円）', lo: 0, hi: 16 }, { key: 'nation', label: '国・市場の桁', lo: 8, hi: 16 }],   // 省略可。省略すると 3 つの桁の範囲
  items: [
    { id: 'salary', name: '年収', value: 480, unit: '万円', group: 'a', counter: '年分', desc: '…', cond: '1 年間・税込', src: [1] },
    { id: 'gdp', name: '名目 GDP', value: 600, unit: '兆円', group: 'b', counter: '倍', desc: '…', cond: '1 年間・名目', src: [1] } ] });
```

- `lo`・`hi` は、基準の単位（円・ドル）の 10 のべき乗の指数。円は 1 円＝0、1 万円＝4、1 億円＝8、1 兆円＝12（上限 16）。ドルは 1 ドル＝0、百万ドル＝6、十億ドル＝9、兆ドル＝12（上限 15）。幅は 2 桁以上。
- `counter` は自由な語。省略すると「倍」。「年分」「回分」と書くと「約 3.2 年分」と出る（「分」は重ねない）。`cond` には、時点・残高か年間か・名目か実質か・円かドルかを必ず書く。
- 免責の既定は「学習用の模型です。実際の投資・取引・契約の判断には使えません。」。講座の定型の注意書き（§3）に合わせるときは `disclaimer` で置き換える。

### 7.B `lab` の線グラフ `fig.type: 'curve'`

x の範囲で式を評価して折れ線を描く。負の値、0 の線、縦の目印、同じ内容の表（折りたたみ）が付く。

```js
fig: { type: 'curve',
  x: { id: 'S', min: 70, max: 130, step: 1, label: '満期の価格', unit: '円' },     // id：式の中の x の名前（入力・定数・calc の名前と重ねない）。step：点の間隔（範囲を 2〜800 に分ける値）
  unit: '円', yLabel: '損益', digits: 1,                                         // 縦軸の単位と名前、表の小数の桁数（既定 2）
  ymin: -20, ymax: 30,                                                          // 数か式。省略するとデータから決める
  series: [{ label: '買い手', expr: 'max(S - K, 0) - p', color: 'ran' },         // 式は x の名前・入力・consts・calc が使える。color は ran / core / pol / ims
           { label: '売り手', expr: 'p - max(S - K, 0)', color: 'pol', dash: true }],   // dash：true / 'dash' / 'dot' / false。色だけで区別しないよう、省略時も 2 本目以降は自動で破線・点線
  marks: [{ x: 'K', label: '権利行使価格' }, { x: 'K + p', label: '損益ゼロ' }],   // 縦の目印。x は式（x の名前は使えない）。各線との交点に点が付く
  alt: '図の説明（必須）', caption: '図の下の説明（任意）' }
```

- 用途ごとの置き方：イールドカーブ（A）は x＝満期までの年数、価格と利回りの関係（A）は x＝利回り、短期金利先物の損益（B）と満期の損益図（C）は x＝満期の価格、グリークスの曲線（C）は x＝原資産の価格。
- 系列は 1〜6 本。式が数にならない点（0 で割る・負の数の対数など）があるとビルド検査がエラー。損益図は**棒で描かない**（線グラフを使う）。
- 満期前の理論価格を重ねる図：入力は `S0`（今の価格）、x の名前は `S` と別にし、`series` の式に `S` から `ncdf` までを 1 つの式で書く（`calc` は x を使えない）。

### 7.C `lab` の式の関数 `ncdf(x)`・`npdf(x)`

標準正規分布の累積分布関数 N(x) と密度関数 n(x)。式（`calc`・`results`・`series`・`reads` の `when`・`marks` など）のどこでも使える。ブラウザとビルド検査で同じ実装（Hart の近似。West 2005）。**絶対誤差はおよそ 1e-15 以下**で、「近似の式を `disclaimer` に書く」必要はない。事実確認表には「`ncdf`＝標準正規分布の累積分布関数（基盤の実装。絶対誤差 1e-15 程度）」と書き、検算の値は `ncdf(0)`＝0.5、`ncdf(1.96)`≒0.9750021、`npdf(0)`≒0.3989423 と照らす。

```js
calc: [{ id: 's', expr: 'sig / 100' }, { id: 'r', expr: 'rr / 100' },
       { id: 'd1', expr: '(ln(S0 / K) + (r + s * s / 2) * T) / (s * sqrt(T))' }, { id: 'd2', expr: 'd1 - s * sqrt(T)' },
       { id: 'C', expr: 'S0 * ncdf(d1) - K * exp(-r * T) * ncdf(d2)' }],
results: [{ label: '買う権利の理論価格', expr: 'C', unit: '円', digits: 2, big: true },
          { label: 'デルタ', expr: 'ncdf(d1)', digits: 3 }, { label: 'ガンマ', expr: 'npdf(d1) / (S0 * s * sqrt(T))', digits: 5 }]
```

入力が S0＝100・K＝100・σ＝20％・T＝0.25 年・r＝1％のとき C は 4.11、デルタは 0.530。
