この章で分かること

  1. 学んだ先の一歩として、Claude Codeを使う準備（契約・アカウント・導入）の見方を説明できる。
  2. このショーケースの「AI エコシステム図」と、リポジトリの設定例（権限・フック・サブエージェント・スキル）が、何を示すかを言える。
  3. 自分の環境を、小さく始めて、少しずつ足す順を確かめられる。

前提：第 04 章までを、必要な範囲で終えていること。ターミナル（文字で操作する画面）を、少し使えると進めやすくなります。

学んだ先の一歩

ここまでの教材は、AI の使い方を学ぶものでした。この章は、学んだことを、自分の作業の中で繰り返し使える環境にするための、最初の一歩です。

Claude Codeは、Anthropic が提供する、AI のコーディング支援ツールです。公式のクイックスタートは、ターミナルに入れて、サインインし、コードのプロジェクトで質問や変更を頼む手順を説明しています。ターミナルのほかに、ウェブ、デスクトップアプリ、Slack でも使える、とも書かれています。VS Code と JetBrains の IDE（統合開発環境）にも対応しています（出典：Anthropic『Claude Code Quickstart』、確認 2026 年 11 月）。

前提も、ページに書かれています。Claude の契約（Pro・Max・Team・Enterprise）、Claude Console のアカウント（プリペイドの API）、または対応するクラウド経由のアクセスのどれかが要ります。契約の料金の額は、このページには書かれていません。使う前に、Anthropic の料金のページで確かめてください。

自分の環境を作る 5 歩

次の図は、環境を作る順の例です。順は、この講座の提案です。公式ドキュメントは、導入のあとの拡張として、CLAUDE.md、スキル、フック、MCP などを挙げています。

図で確かめる点は 3 つです。1 つ目は、最初は、導入と小さな作業だけにすることです。2 つ目は、決まりを書く（CLAUDE.md）と安全柵を足す（権限・フック）を、使いながら足すことです。3 つ目は、繰り返す作業が見えてから、スキルやサブエージェントにすることです。

AI エコシステム図と、リポジトリの設定例

このショーケースには、AI エコシステム図があります。依頼が、入口 → 司令塔（Claude Code）→ ハーネス（安全柵）→ 振り分け → スキル → サブエージェント → 道具・API → 公開、と流れる様子を、図にしたものです。図の箱を押すと、役割・実ファイルのパス・要点が出ます。

図の元になった設定は、このリポジトリの claude/ フォルダにあります。次の表は、そこに実在するファイルを、確認した範囲で説明したものです。

表で確かめる点は 3 つです。1 つ目は、権限ルールが、許可・確認・拒否の 3 つに分かれていることです。2 つ目は、権限だけでは防ぎきれない危険を、フックが止めていることです。3 つ目は、作業の種類ごとに、サブエージェントが分かれていることです。

この設定は、1 つの例です。推奨の設定ではありません。リポジトリの持ち主の作業に合わせて作られています。そのまま入れずに、自分の作業に合うかを確かめて、必要な部分だけを取り入れてください。設定ファイルの書き方は、公式ドキュメントの「設定」「権限」の節で確かめます。

終えるとできること（この章）

この章を終えると、次のことに取り組めるようになります。保証ではなく、目安です。

  • Claude Code を使うための前提（契約・アカウント）を、自分の状況に照らして確かめられる。
  • 権限・フック・サブエージェント・スキルが、何のための仕組みかを、設定例から読み取れる。
  • 自分の環境を、小さく始めて、足していく順を、自分で計画できる。
次の一歩の目安

自分の作業から、繰り返している作業を 1 つ選び、AI に任せる手順と、自分で確かめる手順を、書き出せたら、その作業から始めます。環境は、使いながら足します。

つまずきやすい点

安全柵を、最初に作り込みすぎることです。まず、導入と小さな作業で、動きを知ります。足りない安全柵は、困った場面を見てから足します。反対に、安全柵なしで、強い権限を与えることも避けます。

もう 1 つは、API キーなどの秘密を、設定ファイルに書いて公開することです。このリポジトリの設定例は、秘密のファイルの読み取りを止める仕組みを持っています。ただし、フックや権限は、安全の補助で、すべてを防ぐものではありません。秘密は、公開のリポジトリに載せません。
