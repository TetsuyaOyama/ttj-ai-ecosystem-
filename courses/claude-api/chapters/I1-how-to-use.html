この章で分かること

  1. この講座が公式の資料ではなく、学習用のまとめであることと、最新の情報の確かめ方を説明できる。
  2. 講座の4 つの部の流れと、動かして確かめられる 3 つの部品の場所を言える。

前提：特にありません。プログラミングの経験が浅い人、「黒い画面」（ターミナル）に慣れていない人も読めるように書いています。

お断り：公式の資料ではありません

この講座は、Anthropic の公式の資料ではありません。公式ドキュメントを読んで書いた、学習用のまとめです。モデルの名前、料金、制限、機能、コードの書き方は変わります。実際に使うときは、公式ドキュメント（platform.claude.com）で、最新で正確な情報を確かめてください。この講座は、Anthropic や Claude のロゴ・公式の図版を使わず、公式を装うこともしません。

この講座のゴール

Claude API（クロード・エーピーアイ）は、自分のプログラムから Claude を呼び出すための入口です。チャットの画面で話しかける代わりに、プログラムが文章を送り、答えを受け取ります。この講座は、その最初の 1 回から、仕事の仕組みに組み込むところまでを順に学びます。

全体の流れは、次の図のとおりです。工程を押すか「次へ」で進むと、各段階で何をするかが出ます。

4 つの部と、動かせる部品

講座は 4 つの部に分かれています。行を押すと、その部で何ができるようになるかが出ます。

動かして確かめられる目玉の部品は 3 つです。第 04 章の「リクエストの組み立て」、第 05 章の「料金の見積もり」、第 09 章の「ツール利用の流れ」です。ほかの章にも、図や表や確認問題があります。

事実の扱い方：確認日と、数字の置き場所

この講座の事実は、2026 年 11 月 18 日に公式ドキュメントで確かめたものです。それぞれの章の「参照資料」の表に、資料の名前と、確認日が付いています。確かめられなかったことは、書いていません。

料金とレート制限の数字は、第 05 章の 1 か所だけに書きました。ほかの章は、そこを参照します。数字が変わったときに、直す場所を 1 つにするためです。

コードの例は、公式ドキュメントの現行の書き方に合わせて、短く自分で書きました。構文の検査はしましたが、API を実際に呼んで確かめてはいません。実行すると、手元の環境や API の状態で、違う結果が出ることがあります。うまく動かないときは、第 07 章のエラーの表と、公式のクイックスタートを見てください。

この講座の約束

API キーの実物や、実物に見える文字列は、どこにも書いていません。コードでは「環境変数から読む」書き方だけを使います。

つまずきやすい点

つまずきやすい点

1 つ目は、チャットの画面の Claude と、API は別の入口であることです。画面の使い方を知っていても、API には、キーの準備と支払いの設定が要ります（第 01〜02 章）。2 つ目は、モデルの名前や数字を記憶で書かないことです。古い記事のコードは、今のモデルでエラーになることがあります（第 04 章、第 07 章）。
