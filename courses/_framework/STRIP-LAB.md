# 部品 `strip`（限月の階段）の書き方（2026-11-18 追加。後方互換。FRAMEWORK.md §4.11 の `lab` とは別の部品）

連続する限月の短期金利先物の価格（＝ 100 − 金利）を階段で並べ、金利の曲線の変化（水準 L・傾き S・曲率 K・限月ごとの個別 e）を動かして、限月間スプレッド・バタフライ・コンドルの値と損益を見る実験台。
実装：`js/opt/strip-lab.js`・`css/opt/strip-lab.css`（`strip` を使う章がある講座にだけ埋め込む）。検査：`check-data.js` の `V.strip`。`<div data-widget="strip" data-src="id"></div>`、`CN.add('strip', id, {...})`。

```js
CN.add('strip', 'c16-combo', {
  mode: 'stairs' | 'combo' | 'pnl',      // 階段の図だけ／組み合わせを選び脚を示す／横軸に変化・縦軸に損益
  title, intro, formula, caption, alt (必須), disclaimer (省略可), ch: [章],
  base: [2.00, 2.08, …],                 // 4〜8 個の架空の金利（％）。限月の並び
  names: ['第1限月', …],                  // 省略可
  spec: { name: '商品名', tick: 0.0025, tickYen: 625, cur: '円' },   // 呼値の単位（価格の単位）、1 ティックの価値、通貨の語
  ranges: { L: [-30, 30, 0.5], S: [-6, 6, 0.25], K: [-10, 10, 0.5], e: [-5, 5, 0.25] },   // 省略可（既定は左の値）。[最小(負), 最大(正), 刻み]
  initial: { L, S, K, e: [..], kind: 'spread'|'fly'|'condor', dir: 1|-1, p: 1, gap: 1|2, lots: 1, fx: 'L'|'S'|'K' },   // 省略可
  presets: [{ label, set: { L: 20, S: .., K: .., e4: 5 }, text }]   // stairs・combo のとき。押すと複数のつまみを同時に決める（指定しない変化は 0）
});
```
計算（ブラウザと node で同じ。`CN.strip.calc/sens`）：金利 r_k ＝ base_k ＋（L ＋ S × x_k ＋ K × m_k ＋ e_k）÷ 100（bp）。x_k ＝ k −（n＋1）÷ 2。m_k ＝（q の平均 − x_k²）÷（x_両端² − x_中央²）（中央の限月と両端の限月の金利の差が K bp）。価格 ＝ 100 − r。組み合わせの値 ＝ Σ（重み × 価格）。重み：スプレッド 1・−1、バタフライ 1・−2・1、コンドル 1・−1・−1・1（買い。売りは符号が逆）。損益（ティック）＝ 値の変化 ÷ tick。
狭い画面では、図が sticky で先頭に出る（つまみを動かしながら見られる）。色だけに頼らず、記号（▲▼・買／売 ＋1／−2）、線の種類（実線・破線・点線）で区別する。

## 表の置き場所と凡例（2026-11-18）

- 「内訳」「両端」の表は、2 段組み（`.lab-top`）の外、実験台の全幅に置く（`.st-deco`）。全幅でも収まらない幅では、表の枠（`.tbl-wrap`）が横にスクロールし、端に影が出て、スクロールバーは常に見える。
- 凡例（`.st-key`）は、記号と語を 1 つの塊（`inline-flex`、折り返さない）にして、折り返しても記号と語の対応が崩れない。
