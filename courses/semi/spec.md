### 内容の決まり（全章共通・変えない）

1. 使ってよい情報源は**公開情報だけ**：業界団体の資料（SEMI、JEITA、SEAJ〔日本半導体製造装置協会〕、JEDEC、IEEE IRDS など）、各国当局の公開資料（経済産業省、財務省・税関、植物防疫所、米国商務省 BIS、欧州委員会など）、企業の公開資料（技術解説、決算・IR 資料、プレスリリース）、ICC・JETRO などの公開解説、教科書的な一般知識。有料調査レポートの数字は、発行元が無償で公表した要約に載っている場合だけ使う。
2. **企業名は公開情報の範囲で実名可**。ただし製品の優劣評価・推奨はしない。企業固有の技術ブランド名（例：パッケージ技術の商標）は「◯◯社の呼称」と分かるように書く。個人名、顧客名、勤め先・取引先の非公開情報は書かない。演習・ケースに出す会社は**必ず架空**（「装置メーカー A 社」「顧客 B 社」）とし、実在企業の事故・トラブルを題材にしない。
3. **数字（市場規模、シェア、寸法、価格帯、件数、時期）には必ず出典と時点を付ける**。書式は `GLOSSARY-RULES.md` §5。確認できない数字は書かない（「概算」「推定」で埋めない）。変わりやすい数字は確認問題・総合テストの正答にしない。
4. **安全保障輸出管理**は制度の仕組みの説明にとどめる。個別の貨物・技術の該非判定、取引の可否、許可の要否についての判断や助言はしない。該当する章・節には定型の注意書き（§7.4）を必ず置く。HS コードの分類、関税率、保険の付保条件も同様に個別判断はしない。
5. **投資の推奨や銘柄の評価はしない**。投資サイクルは「指標が何を表し、なぜ時間差が出るか」の仕組みの説明だけ。株価・目標株価・業績予想は書かない。定型の注意書き（§7.4）を置く。
6. 正確さが最優先。確信のない細部は書かず、参照資料を示す（コアネットワーク講義の「詳細は TS xx.xxx を参照」と同じ姿勢）。各章の「執筆時に Web で確認する事実」は、書く前に必ず確認し、確認できたものだけ書く。

## 1. 講座の狙い・読者・到達点

**狙い**：半導体が「何でできていて、どう作られ、どの装置で作られ、その装置がどう運ばれて工場で動き出すか」を一続きで説明できるようにする。装置メーカー・商社・物流の実務者と同じ言葉で話せることを目標にする。

**読者**：理工系の基礎（高校〜大学初年級の物理・化学、単位の扱い）はあるが、半導体は初めての社会人。営業・調達・物流・技術営業・企画・コンサルタントなど。数式は最小限（使うのは第01章のバンドの概念と第08章の解像度の式程度）。

**読み終えた後にできること**

1. ウェーハからチップができるまでの前工程・後工程の流れを、主要な工程名と装置名を使って 5 分で説明できる。
2. 工程の名前を聞いて、どの種類の装置が使われ、その装置がどんな部品（真空・プラズマ・ガス・搬送・温調）でできているかを言える。
3. 「3 nm 世代」「HBM」「チップレット」「High-NA EUV」などのニュースの言葉を、物理寸法・製品・工程のどれの話かに切り分けて読める。
4. 装置が工場を出てから量産に使われるまで（分割・梱包・輸送・通関・搬入・据付・立上げ・受入検査）の段取りと、関係者・書類・記録・リスクを説明できる。
5. インコタームズ・貨物保険・通関・安全保障輸出管理の**仕組み**を理解し、何を誰（所管当局・専門家・社内部門）に確認すべきかが分かる。
6. 装置産業の構造（業態・主要企業・供給網・投資サイクル・各国政策）を、出典付きの公開情報で組み立てて話せる。

### 第1部 半導体の基礎

#### 01 半導体とは何か — 電気を「制御できる」材料
- ねらい：導体・絶縁体との違いと、不純物で電気の通り方を作り分けられることを、バンドの言葉で説明できる。
- 項目：①導体・絶縁体・半導体とバンドギャップ ②電子と正孔（キャリア） ③真性半導体とドーピング（n 型・p 型、ドナー・アクセプタ） ④pn 接合と空乏層、ダイオードの整流 ⑤なぜシリコンか（資源・酸化膜・結晶品質） ⑥化合物半導体（SiC、GaN、GaAs など）の位置づけ ⑦産業で「半導体」が指すもの（材料・素子・IC・産業）
- 部品：`arch`（バンド図の模式：価電子帯・伝導帯・ギャップを 3 物質で切替〔views〕）、`xsec`（pn 接合：p 型と n 型を接合 → 空乏層ができる → 順方向／逆方向の 4 手）、表（主な半導体材料と用途。数値は確認できたものだけ）
- 問：n 型を作るドーパントの種類／空乏層ができる理由／シリコンが主流である理由 ｜ 演：`xsec` で順方向と逆方向を見比べ、電流が流れる側を答える
- Web：シリコン・SiC・GaN のバンドギャップの代表値（室温、出典の教科書・団体資料）
- 資料：物性の教科書、JEITA・応用物理学会の一般向け解説
- 総合テスト 2 問

#### 02 トランジスタ — 電気で電気を切り替える
- ねらい：MOSFET がどう「オン・オフ」するかと、構造がプレーナ → FinFET → GAA と変わった理由を説明できる。
- 項目：①スイッチとしてのトランジスタ ②MOSFET の構造（ゲート・ゲート絶縁膜・ソース・ドレイン・チャネル） ③しきい値電圧とオン・オフ ④短チャネル効果とリーク ⑤プレーナ → FinFET → GAA（ナノシート）の流れ ⑥高誘電率ゲート絶縁膜とメタルゲート（概要） ⑦パワー半導体（MOSFET・IGBT、SiC・GaN）との違い
- 部品：`xsec`（nMOS の断面でゲート電圧を上げるとチャネルができる 4 手）、`arch`（構造の変遷：プレーナ／FinFET／GAA を views で切替。ゲートがチャネルを何面から囲むか）、`state`（MOSFET の状態：オフ／弱反転／オン。押すと条件）
- 問：ゲート絶縁膜の役割／FinFET でリークが減る理由／GAA の「囲む面数」 ｜ 演：`arch` の views を切り替え、ゲートの支配力が増す順に並べる
- Web：FinFET・GAA の量産導入時期と各社の呼称（企業の公開資料）
- 資料：デバイス物理の教科書、IRDS（More Moore）、各社の技術発表
- 総合テスト 2 問

#### 03 集積回路 — CMOS からロジックとメモリへ
- ねらい：トランジスタがどう組み合わさってチップになり、ロジック・メモリなど製品の種類がどう違うかを説明できる。
- 項目：①CMOS（nMOS と pMOS の組）とインバータ ②論理ゲート・スタンダードセル・ブロック・チップ ③ダイ・チップ・ウェーハの関係と、設計（EDA）→ マスク → 製造の流れ ④ロジック（CPU・GPU・SoC） ⑤DRAM（1 トランジスタ 1 キャパシタ）と SRAM ⑥NAND フラッシュと 3D NAND ⑦アナログ・パワー・センサー・ディスクリート
- 部品：`arch`（チップの階層：トランジスタ → セル → ブロック → チップ → パッケージ。押すと大きさの桁と担当工程）、`keys`（製品分類の階層図：半導体 → 集積回路／ディスクリート／光・センサー → ロジック・メモリ・アナログ）、`qos`（製品の種類の早見表：用途・主な構造・製造の特徴）
- 問：CMOS の利点（静止時の電力）／DRAM と NAND の違い／3D NAND で増やしているもの ｜ 演：身近な機器（スマホ・PC・車）から製品の種類を `keys` 上で選ぶ
- Web：3D NAND の最新の積層数（各社の発表、時点）、DRAM の構造の動向
- 資料：教科書、JEITA・WSTS の製品分類、各社の技術解説

#### 04 微細化と世代の呼び方
- ねらい：「◯ nm 世代」が物理寸法ではなく世代の名前であることと、何を小さくしてきたのかを説明できる。
- 項目：①ムーアの法則とスケーリング（何が良くなるか：性能・電力・面積・コスト） ②世代名と物理寸法のずれ（ゲートピッチ・メタルピッチ） ③ロジックの世代呼称（各社の名称、等価比較できないこと） ④DRAM の世代呼称（1x・1y・1z・1α…）と NAND の層数 ⑤IRDS のロードマップの読み方 ⑥微細化を支えた技術の節目（液浸、マルチパターニング、EUV、FinFET、GAA） ⑦微細化だけでない進め方（パッケージ・3D 化）
- 部品：`qos`（世代呼称の早見表：企業・呼称・量産開始の公表時期・出典。数値は出典があるものだけ）、`ident`（ロジック世代名の「読み方」：社名／呼称／数字が表すもの／物理寸法ではない注記）、`arch`（ピッチの模式：ゲートピッチとメタルピッチを指す図）
- 問：「3 nm 世代」の 3 nm が意味するもの／DRAM の 1α とは何の呼び方か／世代を企業間で比べるときの注意 ｜ 演：ニュース見出し 3 本から「世代名」「物理寸法」「製品名」を仕分ける
- Web：各社の世代呼称と量産時期（TSMC・Samsung・Intel・主要 DRAM／NAND メーカーの公開資料）、IRDS の最新版の年、IRDS の世代表記
- 資料：IRDS、各社の技術発表・IR 資料
- **世代の呼び方の「持ち主」章**（他章は第04章へリンク。`GLOSSARY-RULES.md` §4）

#### 05 ウェーハ — 砂から鏡面の円板へ
- ねらい：シリコンウェーハの作り方・寸法・種類と、ウェーハを運ぶ容器を説明できる。
- 項目：①原料（ケイ石 → 金属シリコン → 多結晶シリコン）と純度 ②単結晶の引き上げ（CZ 法、FZ 法） ③インゴット → スライス → 研削・研磨 → 洗浄 ④直径（150・200・300 mm）と 450 mm の経緯 ⑤ノッチ・結晶方位・表裏 ⑥エピタキシャルウェーハ・SOI・SiC ウェーハ ⑦ウェーハの容器（FOUP、FOSB）と出荷
- 部品：`arch`（ウェーハ製造の流れ：工程ノードを左から右へ。押すと装置の種類と主な管理項目）、`qos`（ウェーハ直径の早見表：呼称・直径・主な用途・出典）、`ident`（FOUP と FOSB の違い：用途・扉・搬送の違いを部分で示す）
- 問：CZ 法で作るもの／FOUP と FOSB の使い分け／ノッチの役割 ｜ 演：多結晶シリコンから出荷までの工程を正しい順に並べる（`quiz` の並べ替え形式ではなく 4 択で出す）
- Web：SEMI M1 の現行版の寸法・公差の扱い、シリコンウェーハ出荷面積（SEMI の公表値と時点）、450 mm の開発状況
- 資料：SEMI 規格（M1、E47.1 など）、ウェーハメーカーの技術解説、SEMI の統計発表
- 総合テスト 2 問

### 第2部 製造工程

#### 06 工程の全体像 — 何百もの工程は「同じループ」の繰り返し

- 項目：①前工程と後工程（どこで分かれるか） ②FEOL と BEOL ③基本ループ（成膜・塗布・露光・現像・エッチング・剥離・洗浄・計測） ④マスク層数とループの回数 ⑤ロット・FOUP 単位の流れと AMHS ⑥サイクルタイムと歩留まり ⑦工程と装置の対応（第16章への橋渡し）
- 部品：`xsec`（基本ループ 8 手：成膜 → 塗布 → 露光 → 現像 → エッチング → 剥離 → 洗浄 → 計測。各手に装置の種類）、`xsec`（CMOS を作る簡略フロー 12 手：素子分離 → ウェル → ゲート → ソース・ドレイン → コンタクト → 配線）、`seq`（ロットの旅：搬送・成膜・リソ・エッチ・洗浄・計測の装置間を FOUP が移る）
- 問：FEOL と BEOL の境目／基本ループの順序／歩留まりの定義 ｜ 演：`xsec` の各手で「次に使う装置」を答える
- Web：先端ロジックのマスク層数・工程数の公開例（出典がなければ数字を書かない）、サイクルタイムの公開例
- 資料：プロセスの教科書、IRDS、装置メーカーの一般向け解説
- 対応表：工程⇔装置の行（全種別の代表 1 行ずつ）
- 総合テスト 2 問

#### 07 酸化と成膜
- ねらい：膜をつける方法（熱酸化・CVD・ALD・PVD・エピ）の違いと使い分けを説明できる。
- 項目：①膜の役割（絶縁・導電・保護・マスク） ②熱酸化（ドライ・ウェット） ③CVD（熱 CVD・LPCVD・PECVD） ④ALD（1 原子層ずつ、段差被覆） ⑤PVD（スパッタリング）とターゲット ⑥エピタキシャル成長 ⑦膜質の指標（膜厚均一性・段差被覆・応力）
- 部品：`xsec`（段差への付き方の比較：PVD／CVD／ALD を同じ溝に成膜する 3 手。被覆の違い）、`qos`（成膜方式の早見表：原理・温度帯の傾向・得意な膜・装置の形態）、`seq`（ALD の 1 サイクル：前駆体供給 → パージ → 反応ガス → パージ）
- 問：ALD が段差に強い理由／スパッタのターゲットとは／熱酸化で消費されるもの ｜ 演：用途（ゲート絶縁膜、配線のバリア、層間絶縁膜）に合う方式を選ぶ
- Web：ALD・PECVD の代表的な用途の最新動向（装置メーカーの公開資料）
- 資料：教科書、装置メーカー技術解説、材料メーカーの前駆体解説
- 対応表：成膜の行

#### 08 リソグラフィ（1）露光
- ねらい：露光で回路の形を写す原理と、解像度を決める要素、光源の世代を説明できる。

### 6.3 追加したい部品（2 つ）

既存部品で表せるか検討した結果：

- 装置の断面構成図 → **`arch` で足りる**（ノードの矩形を自由に置け、`groups` で筐体・チャンバ壁、`views` で装置の種類を切替、線で配管・電源・排気を表せる）。
- 工程フローを順に進める図 → 工程**間**の流れは `seq` で足りるが、**ウェーハの断面が一手ごとに変わる様子**（膜が付き、レジストが残り、溝が彫られる）は表せない。`stack` は全幅の層しか描けず横方向のパターンがなく、手順の再生もない。→ **追加 1：`xsec`**。
- 輸送の行程図 → 登場者間のやり取りは `seq` で足りる。だが「**区間のどこで費用と危険が売主から買主へ移るか**」「どの区間にどのリスクがあるか」を、条件を切り替えて同じ行程の上で比べる図は、`seq`（矢印の順序）でも `qos`（表）でも表せない。→ **追加 2：`route`**。

- **材料 `m` は部品が持つ固定の一覧**から選ぶ（全章で同じ材料は同じ色になる）：`si`（シリコン）`si-n`（n 型領域）`si-p`（p 型領域）`sio2`（酸化膜）`sin`（窒化膜）`poly`（多結晶シリコン）`hk`（高誘電率膜）`metal`（金属一般）`cu`（銅）`w`（タングステン）`al`（アルミ）`barrier`（バリアメタル）`lowk`（低誘電率膜）`resist`（レジスト）`resist-exp`（露光部）`mold`（封止樹脂）`bump`（はんだ・バンプ）`substrate`（パッケージ基板）`void`（空洞・溝）。色は CSS 変数 `--m-si` などで定義し、ダーク・ライトの両方でコントラストを確保（土台担当）。足りない材料は土台担当に依頼する（章で色を作らない）。
- 図の下に**凡例**（その図で使った材料だけ）。凡例を押すとその材料を強調し、名称・英語名・役割を表示。
- 操作は `seq` と同じ：再生／一時停止／前へ／次へ／最初へ／スライダー／速度（0.5×・1×・2×）／手順の一覧／矢印キー・Space。
- 一手ごとに、追加・変更された図形を枠で強調し、説明パネルに `name`・`proc`・`equip`・`what`・`trap`・関連章を出す。
- `prefers-reduced-motion` では演出（`fx`）の動きを止め、静止の矢印だけ出す。
- 読み上げ用に、各手の `name` と `what` を本文として出す（図だけに情報を持たせない）。検索の対象：`title`・`name`・`proc`・`equip`・`what`。
- ビルド検査：`del`・`mod` の id が既にあること、`m` が一覧にあること、図形が `viewBox` からはみ出さないこと。
- 1 本あたり 4〜12 手。図形は 1 手あたり 6 個程度まで（狭い画面で読めるように）。
