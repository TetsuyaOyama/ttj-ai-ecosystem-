## 守るべき線の確認

- **第29章（見通し）**：冒頭に「公表されている計画・見通しの整理で、予測・優劣の評価・投資の推奨ではない」の注意書きがある。早見表・本文の時期は、すべて主体と時点つきの「予定」「計画」「見込み」「試作の発表」と書かれ、断定や予言はない。量産時期が確認できない項目（ガラス基板、3D DRAM、300 mm SiC）は「書かない」と明記。性能の数値は使っていない。演習の見出しはすべて架空と明記。
- **第30章（政策と投資サイクル）**：冒頭に §7.4 の「投資」の定型文がある（文言は spec どおり）。投資サイクルの節は、受注 → 出荷 → 検収 → 売上の時間差と、指標の先行・遅行の仕組みの説明だけで、相場の見通し、投資の推奨、銘柄・企業の評価、株価・業績予想はない。演習の A 社と数値は架空と明記。政策の表には「優劣の評価ではない」の注記がある。「未確認」の表示は、中国の行・台湾の上限・韓国の施行日で適切に使われている（台湾・韓国は今回の修正で表示を足した）。
- **第31章（案件）**：冒頭で、A〜E 社が架空で、実在企業の内部事情・実在の案件ではないと明記。案件の流れ（契約 → FAT・出荷判定 → 輸出申告〔他法令の許可書を添付〕→ 主運送 → 輸入通関 → 荷受け → 据付・立上げ → SAT → 検収 → 保守）は、第21章（出荷判定）、第25章（検収・保証期間は契約で決まる）、第26章（DAP の危険の移転、輸入通関は買主）、第27章（見積の段階から確認）、第28章（受取書への記載）と食い違いはない（食い違っていたのは M7 の正答と S7 の輸入地の通関業者で、直した）。輸出管理の場面は §7.4 の定型文を置き、「見積の段階から確認を始め、許可が必要なら日数がかかる」という仕組みの説明と、確認先（社内の輸出管理部門、所管当局）を示すだけで、個別の該非や許可の要否を例示していない。支払条件は割合を示していない。演習・確認問題・総合テストの答えは全件確認し、M7 以外の誤りはない。
- **第32章（付録）**：「この講座が扱わないこと」に、個別の判断（該非、許可、HS、関税率、保険）と投資判断を挙げ、§7.4 の輸出管理の定型文がある。
