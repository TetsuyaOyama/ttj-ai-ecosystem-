この章の「公開情報で確認できた範囲」

団体・規格・当局の名前と、確認できた版・時点は、各章の「参照資料」と事実確認で確かめた内容を集めたものです。この章で新しく数字や版を足してはいません。確認できなかったものは、書いていません。

規格は改訂され、当局の担当部署名は組織の改編で変わります。実務で使うときは、必ず発行者の公式ページで最新の版と窓口を確認してください。規格の本文は、この講座では転載していません。

② 規格・団体の地図と、公的資料の地図

計算サーバーには、たくさんの規格と団体が関わります。名前だけを覚えると、混ざります。分野から、団体、規格・資料の順にたどると、整理できます。下の図は、2 つの見方を切り替えられます。「規格・団体」は、標準化団体と業界団体の見方です。「公的資料」は、当局・公的機関の見方です。箱を押すと、何が載っているかと、関連する章が出ます。

図で、次の点を確かめます。

  • 形状・相互接続・ストレージ・ネットワークは、団体ごとに規格が分かれています。PCIe は PCI-SIG、DDR は JEDEC、NVMe は NVM Express、イーサネットは IEEE のように、分野と団体を組にして覚えます。
  • 電源と冷却と施設の規格は、別の団体の系統です。空調と熱は ASHRAE、効率の指標は The Green Grid と ISO/IEC、施設の格付けは Uptime Institute などです。
  • 団体の規格は、法令ではありません。規格を使うかどうかは、契約や顧客の仕様書で決まります。法令と制度は、当局の資料で確認します。
  • 輸出管理と補助制度は、団体の規格ではなく、当局の制度です。個別の判断は、所管当局と社内の専門家に確認します（第30章）。

⑦ この講座が扱わないこと

この節の扱い

この節は制度の仕組みの説明です。個別の製品・技術・取引について、該非判定、許可の要否、取引の可否を判断するものではありません。実際の判断は、所管当局（日本では経済産業省 安全保障貿易管理の窓口）と、社内の輸出管理部門・専門家に確認してください。

この講座は、仕組みと用語を説明するものです。次のことは、扱っていません。

  • 個別の判断と助言：機器の該非判定、輸出の許可の要否、取引の可否、設備の設計値、契約条件の評価。これらは、個別の案件と契約で決まります。所管当局、社内の専門部門、有資格の専門家に確認します。
  • 作業の手順：電気・直流・蓄電池・冷却液・冷媒・消火ガス・重量物に関わる作業は、仕組みと注意点だけを説明しています。手順書の代わりにはなりません。作業は、法令で定められた有資格者が、現場の手順に従って行います。
  • 投資の判断と費用の判断：産業と制度、費用の構造の説明で、投資の推奨や、特定の企業・銘柄・製品の評価ではありません。金額の例は架空です。
  • 製品の順位づけと、企業の優劣：製品名と会社名は、公開情報の範囲で、例として出しています。
  • 攻撃の手順：セキュリティは、仕組みと対策の考え方だけです。
  • 企業の内部の事情：演習に出る会社名は、すべて架空です。
  • 規格の本文：規格と規則の本文は、転載していません。必ず、発行者の最新の版を確認します。
つまずきやすい点

規格の番号は、団体ごとに別の体系です。IEEE の 802.3、JEDEC の JESD79-5、ISO/IEC の 22237 は、団体も分野も違います。番号だけでなく、発行者と一緒に覚えます。

団体は規格を作るだけで、法令ではありません。規格を使うかどうかは、契約や顧客の仕様書で決まります。

版は変わります。各章の版や時点は、執筆時（2026 年 11 月）に確認した内容です。

現場でのつながり

仕様書や契約に、規格の番号が出てきたら、この章の地図で、発行者と分野を確かめます。そのあと、発行者の公式ページで、版を確認します。
