この章で分かること

  1. メモリの載せ方（DIMM の種類、メモリチャネル、NUMA）と、それが性能の「近い・遠い」に効く理由を説明できる。
  2. 「PCIe 5.0 x16」「DDR5-6400 RDIMM」のような表記を、規格・世代・レーン数・速度等級・種類に切り分けて読める。
  3. CXL がメモリの拡張・共有をどう可能にするかと、世代の見方（Type 1・2・3）を言える。

前提：第06章（CPU サーバーの中身）。メモリの誤り訂正（ECC）は第05章を読んでおくと分かりやすくなります。

DIMM の種類と ECC

メインメモリは、DIMM（Dual In-line Memory Module）という細長い基板で、サーバーに差します。DIMM には、いくつかの種類があります。違いは、CPU とメモリチップの間に、信号を整える部品を入れるかどうかです（出典：一般知識）。

  • UDIMM（Unbuffered DIMM）：信号を整える部品がない DIMM です。
  • RDIMM（Registered DIMM）：レジスタという部品を載せた DIMM です。CPU の電気的な負担が減り、1 チャネルに多くの容量を載せやすくなります。サーバーで広く使われます。
  • LRDIMM（Load-Reduced DIMM）：データの信号にもバッファを入れ、さらに多くの容量を載せやすくした DIMM です。

サーバー向けの DIMM には、誤りを訂正する ECC（Error-Correcting Code）つきのものが一般的です（第05章）。DDR5 の規格番号は JESD79-5 で、JEDEC が 2020 年 7 月 14 日に新規格として公表しました。1 枚の DIMM に、独立したサブチャネルが 2 つあります（出典：JEDEC、2020 年 7 月 14 日）。

DIMM の名前は、世代・速度等級・種類を 1 つにまとめた表記です。下の図で分けて読みます。値は、規格や製品仕様に載っている例です。

メモリチャネルと、帯域幅の考え方

CPU とメモリは、メモリチャネル（memory channel）という、独立した通り道でつながります。チャネルが多いほど、同時に運べるデータが増えます。1 つの CPU が持つチャネルの数は、CPU 製品で決まります（第06章の表）。

メモリ全体の帯域幅は、おおまかに、「チャネルの数」と「1 チャネルの速度」で決まります。1 チャネルに何枚の DIMM を差すかも、速度に影響します。載せ方の決まりは、サーバーのメーカーが示す構成表に従います。チャネルを使い切らずに、DIMM を少なく載せると、帯域幅が下がることがあります。

NUMA：近いメモリと遠いメモリ

2 ソケットのサーバーでは、各 CPU に、自分に直結したメモリがあります。相手の CPU に直結したメモリも使えますが、ソケット間リンクを通ります。このため、待ちが長くなりやすくなります。この構成を、NUMA（Non-Uniform Memory Access）と呼びます。「メモリへの近さが、一様でない」という意味です。

図の上のタブで、「近いメモリ」と「遠いメモリ」を切り替えてください。NIC や SSD のような PCIe の機器も、いずれかの CPU につながります。機器と同じソケットに、アプリのコアとメモリを寄せると、遠い経路を避けられます。

PCIe：レーン・世代・x16

PCIe（PCI Express）は、CPU と、拡張カード・SSD・NIC・GPU などをつなぐ高速な接続の規格です。PCI-SIG が定めています。接続の太さは、世代とレーンの数で決まります。レーンは、送受信の信号線の組です。レーンを何本束ねるかを、「x16」のように書きます。

CPU の側で、PCIe の接続の起点になる部分を、ルートコンプレックス（root complex）と呼びます。CPU 製品ごとに、使えるレーンの数が決まっています。たとえば、Intel（米国）の Xeon 6980P のページは、PCIe 5.0 で最大 96 レーンと記しています（出典：Intel『Intel Xeon 6980P Processor Product Specifications』、確認 2026 年 11 月）。

スロットの形が x16 でも、中の配線が x8 のことがあります。仕様表で、実際の接続の幅を確かめます。

リタイマと PCIe スイッチ

PCIe の信号は、速度が上がるほど、基板の上で弱くなりやすくなります。そこで、リタイマ（retimer）という部品が、信号を整え直して送り出し、届く距離を延ばします。CXL 4.0 の発表は、最大 4 つのリタイマを使えるようにする、と述べています（出典：CXL Consortium、2025 年 11 月 18 日）。

PCIe スイッチ（PCIe switch）は、1 つの上流の接続を、複数の下流の機器に分ける部品です。GPU を多数載せるサーバーで、GPU や NIC をつなぐために使います（第08章）。

CXL：メモリを拡張し、共有する

CXL（Compute Express Link）は、CPU と、アクセラレータやメモリ装置の間で、メモリを拡張・共有できるようにする規格です。CXL Consortium が定めています。デバイスの型は 3 つです（出典：CXL Consortium の 2023 年の資料）。

  • Type 1：メモリをもたないアクセラレータ。CXL.io と CXL.cache を使います。例は NIC です。
  • Type 2：メモリをもつアクセラレータ。CXL.io、CXL.cache、CXL.mem を使います。例は GPU や DPU です。
  • Type 3：メモリの拡張装置。CXL.io と CXL.mem を使います。メモリの帯域幅や容量を増やす、プーリングに使います。

CXL の「CXL.io」「CXL.cache」「CXL.mem」は、運ぶ内容の違う 3 つのプロトコルの名前です。メモリプーリング（memory pooling）は、複数のサーバーが、メモリ装置の容量を分け合って使う仕組みです。CXL 3.0 の発表は、メモリのプーリングと共有の強化を、機能の 1 つに挙げています（出典：CXL Consortium、2022 年 8 月 2 日）。

世代の早見表

PCIe と CXL は、世代が進むたびに、転送速度が上がります。次の表は、各団体の発表にある値を、そのまま並べた早見表です。行を押すと、補足が出ます。

メモリの新しい形

MRDIMM（Multiplexed Rank DIMM）は、メモリの帯域幅を上げる、新しい形の DIMM です。JEDEC は 2024 年 7 月 22 日に、DDR5 の MRDIMM を JC-45 委員会で策定中と発表し、素の DRAM の最大 2 倍の帯域幅をめざすと述べました（出典：JEDEC、Business Wire 配信、2024 年 7 月 22 日）。この講座では、その後の規格化の状況を、一次資料で確認できませんでした。製品側では、Intel の Xeon 6980P のページが、MRDIMM 8800 MT/s への対応を記しています。

もう 1 つの流れが、CXL のメモリ拡張装置です。SNIA の 2024 年の資料は、E3.S 2T と E1.S という SSD の形状が、CXL のメモリモジュールに x8 のコネクタを使う、と述べています（出典：SNIA『The Latest on Form Factors』、2024 年）。形状は第09章で扱います。

つまずきやすい点

「速度」の言葉を混ぜないことです。メモリの速度等級は MT/s、PCIe と CXL の転送速度は GT/s、帯域幅は GB/s で、単位が違います。「GT/s」は 1 レーンの転送の回数、「GB/s」は運べるデータの量です。

世代とレーン数は別です。PCIe 5.0 x8 と PCIe 4.0 x16 のように、世代の違う接続を、レーン数だけで比べないでください。

CXL は PCIe の言い換えではありません。CXL は、メモリの拡張・共有やキャッシュの一貫性など、PCIe にない機能を扱う規格です。

現場でのつながり

サーバーの構成を決めるときは、CPU の PCIe レーン数と、NIC・SSD・GPU のレーンの割当て、DIMM の載せ方（チャネルの使い切り）を、構成表で確認します。性能が出ないときは、NUMA の「遠い」経路を通っていないかも、疑います。
