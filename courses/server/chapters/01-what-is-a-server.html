この章で分かること

  1. 計算機が演算・制御・記憶・入出力の組でできていることと、プログラム内蔵方式の要点を説明できる。
  2. サーバーが PC と何が違うか（連続稼働、遠隔管理、冗長、拡張、設置）と、用途ごとに重くなる部品を言える。
  3. データセンターが IT 機器・電源・冷却・建屋・管理の 5 つでできていることと、本講座の地図、W と Wh の違いを説明できる。

前提：なし。高校〜大学初年級の物理・電気の知識があれば読めます。

計算機は、四つの働きの組でできている

計算機（コンピュータ）は、演算・制御・記憶・入出力の四つの働きでできています。演算は計算をする働き、制御は命令を順に読んで各部を動かす働きです。記憶はデータと命令をためる働き、入出力は外の世界とデータをやり取りする働きです。入力と出力を分ければ、五つの働きと数えることもあります（出典：Patterson・Hennessy 著『Computer Organization and Design』の計算機の基本構成の説明）。

現在の計算機の多くは、プログラム内蔵方式（stored-program architecture）で動きます。プログラム（命令の並び）を、データと同じ記憶装置に置いておく方式です。命令を入れ替えるだけで、同じ機器が別の仕事をします。配線を組み替える必要はありません。サーバーも、この方式の計算機です。

データはどう流れるか：1 件の要求の処理

サーバーの仕事の多くは、ネットワークから届く「要求」に答えることです。要求が届いてから応答を返すまでの間に、データは、ネットワーク、メモリ、CPU、ストレージの順に動きます。一般的な流れを、下の図で一手ずつ確かめてください。

この図で大事なのは、どの部品も、待たされる可能性があることです。必要なデータがメモリにあれば、ストレージの読み出しは要りません。なければ、CPU はデータの到着を待ちます。部品ごとの待ちの違いは、第02章で扱います。

サーバーとは何か

サーバー（server）は、ネットワーク上で資源を管理する計算機や機器です。NIST（米国国立標準技術研究所）の用語集は、この定義に、ファイルサーバー、印刷サーバー、データベースサーバーなどの例を添えています（出典：NIST『Computer Security Resource Center Glossary』の「server」の項、2026 年 11 月に確認）。

「サーバー」という語は、二つの意味で使われます。一つは、サービスを提供するプログラムです。もう一つは、そのプログラムを動かす機器です。本講座は、断りがなければ、機器のほうを指します。

では、PC と何が違うのでしょうか。サーバーは、人が前に座って使うためではなく、止めずに動かし続け、遠くから管理するために作られます。その違いが、部品の選び方、設置の仕方、冗長の持たせ方に表れます。下の表は、考え方の違いの一般論です。製品によって例外があります。

サーバーは何のために使われるか

サーバーの使い方（ワークロード、workload）は、大きく五つに分けられます。用途によって、重くなる部品が違います。機器を選ぶときは、まず用途を見ます。

用途ごとに重くなりやすい部品（一般論）
用途主な仕事重くなりやすい部品
Web・アプリケーション多数の利用者からの要求を、順に処理して返すCPU とネットワーク
データベースデータを探し、更新し、正しさを保つメモリとストレージ
ストレージ大量のデータを保管し、読み書きに応じるストレージとネットワーク

AI の学習と推論の違いは第08章で、HPC のジョブの割り当ては第22章で説明します。

データセンターの全体像

サーバーは、単独では動きません。電気が要り、熱を捨てる必要があり、守る建物が要り、全体を見る仕組みが要ります。サーバーをまとめて置き、これらを備えた施設がデータセンター（data center）です。

国際規格 ISO/IEC 22237-1 は、データセンターの設備とインフラの用語・参照モデル・分類の枠組みを定めています。電力・冷却・建物・管理を、一組の枠組みで扱う考え方です（出典：IEC『ISO/IEC 22237-1:2021』の規格ページ、第1版、2021 年 10 月 5 日。規格本文は読んでいません）。本講座も、データセンターを次の 5 つに分けて見ます。

  • IT 機器：サーバー、ストレージ装置、ネットワーク機器。
  • 電源：受電から機器までの電力の設備。
  • 冷却：機器の熱を建物の外へ捨てる設備。
  • 建屋：サーバー室、電気室、機械室など、設備を収める建物。
  • 管理：機器と設備を見て、制御し、記録する仕組み。

どこに置くか：オンプレミス・コロケーション・クラウド

サーバーを置く場所には、大きく三つの形があります。自社の施設に置くオンプレミス（on-premises）、データセンター事業者の施設の一部を借りて自社の機器を置くコロケーション（colocation）、事業者のサーバーを借りて使うクラウドです。違いは、誰が機器を持ち、誰が施設を運用するかにあります。詳しくは、コロケーションとクラウド事業者を第26章、クラウドの提供形態を第04章、比べ方の枠組みを第29章で扱います。

本講座で使う単位：W と Wh、bit と byte

電力の単位はW（ワット）です。1 秒あたりの電気エネルギーの量を表し、「いま、どれだけの電気を使っているか」の大きさです。ワットは、1 秒あたり 1 ジュールのエネルギーの流れとして定義されています（出典：BIPM『SI Brochure』第9版、付録 1）。これに時間をかけた量が、Wh（ワット時）です。「ある時間に、合計でどれだけ使ったか」を表します。電気料金や電力量の統計は Wh の仲間（kWh、MWh）で書かれ、機器の仕様や設備の容量は W の仲間（kW、MW）で書かれます。

データの単位にも、似た注意があります。bit（ビット）は 0 か 1 かの 1 桁、byte（バイト）は 8 bit のまとまりです（一般知識）。通信の速さは bit で、記憶の容量は byte で書くのが普通です。表記は、通信が「Gb/s」、データ量が「GB」のように、小文字の b と大文字の B で区別します。

演習：用途と、重くなる部品

次の 3 つの用途（架空）で、負荷が最も重くなりそうな部品を、CPU・メモリ・ストレージ・ネットワーク・アクセラレータから選んでください。考えてから、答えを開きます。

  1. A 社の商品紹介サイト。多数の閲覧者が、短い要求を同時に送る。
  2. B 社の研究室。画像を認識するモデルを、大量のデータで学習する。
  3. C 社の部門のファイル共有。大きなファイルを多数の社員が保存・取得する。
答えを見る

① Web 配信は、小さな要求の数が多いので、CPU とネットワークが重くなりやすい用途です。ただし、データをデータベースから取るなら、メモリとストレージも効きます。

② 学習は、大量の並列計算が中心なので、アクセラレータ（GPU など）が重くなります。複数の機器で分担するなら、ネットワークも効きます（第08章・第11章）。

③ ファイル共有は、保管と読み書きが中心なので、ストレージとネットワークが重くなりやすい用途です。

どの用途も「1 つの部品だけ」とは限りません。最も遅い部品が全体を決める考え方は、第02章で扱います。

つまずきやすい点

W と Wh を混ぜないこと。「ラックあたり ◯ kW」は大きさ（いまの電力）の話で、「年間 ◯ GWh」は使った量の話です。W に時間をかけると Wh になります。

もう一つ。「サーバー」は、プログラムを指すことも、機器を指すこともあります。文脈で読み分けてください。

現場でのつながり

引合いや商談では、最初に「何の用途か」を聞くと、必要な機器の方向が決まります。用途から部品、部品から電力と熱、熱から冷却へと、本講座の章は同じ順序でつながっています。
