この章で分かること

  1. 汎用の CPU サーバーの筐体の中で、何がどこに置かれ、空気・電力・信号がどう流れるかを説明できる。
  2. ソケット、メモリスロット、拡張スロット、電源ユニット、ファンの役割と、FRU（現場で交換する部品の単位）の考え方を言える。
  3. TDP・消費電力・定格を区別し、CPU 製品の公開仕様の表を、定義に気をつけて読める。

前提：第02章（主要部品）、第03章（形状と規格）。あるとよい：第05章（冗長・ホットスワップ）。

筐体の中を、前から後ろへ見る

サーバーの筐体は、前から後ろへ並べて読むと、分かりやすくなります。空気は、ラックの前面から入り、背面から出ます（第03章）。前面には、ドライブを差す区画があります。その奥にファン列があり、さらに奥に CPU とメモリ、背面に拡張カードと電源ユニットがあります。

下の図は、2U のサーバーを上から見た模式図です。2U は、高さが 2 ラックユニット（第03章）の筐体です。部位を押すと、役割と、FRU か、交換時の注意が出ます。形・数・位置は製品で違います（出典：一般知識）。

CPU（Central Processing Unit）の上には、ヒートシンクが付きます。エアシュラウドは、空気を CPU とメモリの間へ導くカバーです。ファンが送った空気が、わきへ逃げずに、冷やしたい部品を通るようにします。

結線：電力・データ・管理

筐体の中では、3 種類のものが流れます。電力は、電源ユニットから基板とファンへ届きます。データは、CPU を中心に、メモリ・拡張カード・ストレージとの間を行き来します。管理の信号は、基板管理コントローラ（Baseboard Management Controller, BMC）が、温度と電源の状態を読み、ファンを制御するために使います。BMC の詳細は第19章です。

この図は、2 ソケットの構成の例です。ソケットが 1 つの製品は、CPU 1 とその周りの部品がありません。部品の数は、製品で違います。

マザーボードとソケット

マザーボード（motherboard）は、部品をつなぐ土台の基板です。CPU を載せる受け口がソケット（socket）で、1 台のサーバーに 1 つ載せる構成を 1 ソケット、2 つ載せる構成を 2 ソケットと呼びます。

ソケットの数は、製品で決まります。Intel（米国）の製品仕様ページは、Xeon 6980P のスケーラビリティを「2S」と記しています。2S は、2 ソケットの構成まで、という意味です（出典：Intel『Intel Xeon 6980P Processor Product Specifications』、確認 2026 年 11 月）。NVIDIA（米国）は、Grace CPU Superchip を、「2 ソケットのサーバーの中心を小さなモジュールにしたもの」と説明しています（出典：NVIDIA『Introducing the NVIDIA Grace CPU Superchip』、確認 2026 年 11 月）。

2 ソケットでは、各 CPU に直結したメモリがあります。相手の CPU に直結したメモリを使うときは、ソケット間リンクを通ります。このため、メモリには「近い」と「遠い」ができます。詳しくは第07章で扱います。

メモリスロット・拡張スロット・ライザーカード

メモリは、DIMM（Dual In-line Memory Module）という細長い基板で、メモリスロットに差します。スロットは、CPU から出るメモリチャネルごとに並びます。DIMM の種類とチャネルは、第07章です。

拡張カード（NIC、GPU、ストレージのコントローラなど）は、PCIe（PCI Express）のスロットに差します。薄い筐体では、カードを寝かせて差すために、ライザーカード（riser card）を使います。ライザーカードは、マザーボードに差す小さな基板で、その上にスロットがあります。NIC（Network Interface Card）には、背面から抜き差しできる OCP NIC 3.0 の形を使う製品があります（第03章）。

前面のドライブベイ（drive bay）には、SSD や HDD を差します。ドライブの形状と接続の規格は第09章が持ち主です。

電源ユニット

電源ユニット（Power Supply Unit, PSU）は、施設から来る電力を、機器の中で使う電圧に変える部品です。サーバーには、PSU を 2 台以上入れて、冗長にする製品が多くあります。1 台が止まっても、残りで動き続けるためです。2 台を別々の給電系統（A 系・B 系）につなぐ使い方もあります（第05章）。

冗長な PSU は、稼働したまま取り替えられる（ホットスワップ、hot swap）製品が多くあります。PSU の効率の等級と、ラックへの給電は第14章が持ち主です。電力が機器へ届くまでの流れは第12章です。

ファンと風の通り道

CPU やメモリは、熱を出します。この熱を運び出すのが、ファンと風の通り道です。前面から吸った空気が、ファン列に押されて、CPU・メモリ域を通り、背面へ抜けます。通り道を決めるのがエアシュラウド（air shroud）です。

ファンは、複数を並べて冗長にする製品が多くあります。1 個が止まったとき、他のファンの回転数を上げて補う設計が一般的です（出典：一般知識。製品で異なる）。空気の流れとラック全体の冷却は第15章が持ち主です。

保守部品の単位：FRU

FRU（Field Replaceable Unit）は、現場で、保守する人が取り替えられる部品の単位です。PSU、ファンモジュール、DIMM、ドライブ、ライザーカードなどが、FRU として扱われます。マザーボードのように大きな部品も、FRU です。ただし、交換には多くの部品を外す必要があります。

FRU の考え方があると、障害のとき、「どの部品を取り替えれば直るか」を、メッセージから決めやすくなります。交換のしかたは、機器のメーカーの保守文書が正です。

この章の扱い

この章は、サーバーの筐体の仕組みの説明です。保守作業の手順書の代わりにはなりません。実際の部品の取り外し・取付けは、メーカーの保守文書と、現場の手順に従ってください。

部品ごとに、冗長にするか、停止して交換するかをまとめた表です。行を押すと補足が出ます。

CPU 製品の公開仕様と、TDP の読み方

CPU の仕様は、各社が公開しています。次の表は、3 社の公開資料にある値を、そのまま並べた例です。比較や順位を示すものではありません。数字は、製品・世代・時点で変わります。

表の「電力の値」に、TDP（Thermal Design Power）が出てきます。TDP は、冷却と電力の設計の目安として、メーカーが示す電力の値です。Intel は、TDP を「最大の理論上の負荷のときの消費電力（W）」と説明しています。軽い負荷では、消費電力は TDP を下回ります。ターボなどで、一時的に TDP を超えることもある、と書いています（出典：Intel『Thermal Design Power (TDP) in Intel Processors』、ページ表示の最終確認日 2023 年 4 月 4 日）。

この講座では、3 つの言葉を、次のように使い分けます。消費電力は、実際に使っている電力です。定格は、機器に表示された上限の値です。TDPは、熱設計の目安です。同じ「電力」でも、意味が違います。AMD（米国）の発表は「既定の TDP」と書き、NVIDIA の Grace CPU Superchip のページは「CPU とメモリで 500 W」と書いています。資料ごとに、言葉の意味が違うので、比べる前に、各社の定義を読んでください。

演習：障害メッセージから FRU を選ぶ

3 つの障害メッセージ（すべて架空）から、交換する FRU を選びます。まず、どの部品かを自分で決めてから、行を押してください。答えと、考える順序が出ます。

つまずきやすい点

TDP は、実際の消費電力ではありません。TDP を、サーバーの電力の見積りにそのまま足すと、実際とずれます。電力の設計は、機器全体の定格と、負荷の見込みで行います（第12章、第14章）。

「ホットスワップできる」は、製品で違います。表の「一般論」は、多くの製品の傾向です。実際に稼働したまま交換できるかは、その製品の保守文書で確認してください。

エアシュラウドは、小さな部品でも、冷却に効きます。外したまま動かすと、空気が通らず、温度が上がることがあります。

現場でのつながり

機器の選定では、ソケット数、メモリチャネル数、拡張スロットの数と世代、PSU の冗長を、仕様表で確かめます。運用では、障害メッセージから FRU を特定し、保守業者に伝える部品名がそろっていると、復旧が早くなります。
