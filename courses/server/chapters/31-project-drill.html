この章で分かること

  1. 計算サーバーの導入案件を、要件から設計、調達、製造・統合、輸送、設置、立上げ、受入、運用、更新・廃棄まで、流れと関係者で追える。
  2. IT と施設の取り合い（電力・冷却・床・ネットワークの境界）、マイルストーンと受入条件、議事録と変更管理の役割を説明できる。
  3. 案件の場面（症状）から、どの局面・どの取り合いの問題かと、最初に動く担当を、第01〜30章の内容を使って挙げられる。

前提：第11章、第12章、第17章。第28〜30章（搬入と立上げ、調達、制度）を読んでから取り組むと、演習が解きやすくなります。

この章の扱い

この章は、新しい事実を足しません。第01〜30章の内容と、案件管理の一般的な考え方だけで作っています。演習の場面・症状・記録はすべて架空で、特定の企業・製品・案件を指しません。取り合いの責任の分け方は一般例で、実際は案件の契約と取り合い表で決まります。

案件の流れと関係者

導入案件は、おおむね次の順に進みます。要件 → 設計 → 調達 → 製造・統合 → 輸送 → 設置 → 立上げ → 受入 → 運用 → 更新・廃棄。各段階に、持ち主の章があります（要件と調達は第29章、電力は第27章、搬入から受入は第28章、制度は第30章、運用は第23章）。

関係者は多く、それぞれが別の情報を持ちます。

  • 顧客：IT 担当（機器の要件）、施設担当（設置先の条件）、購買・契約担当（調達と契約）。
  • ODM・OEM・インテグレータ：機器の製造・統合・出荷（第26章）。
  • DC 事業者：建屋、受電、搬入経路、運用。設備業者：電源・冷却の工事と試運転。電力会社：系統の接続、受電。
  • 当局：効率の報告や輸出管理などの制度（第30章）。

下の図は、案件の全体を、顧客・ODM／OEM・DC 事業者・設備業者・電力会社の動きで追います。局面ごとに、誰が誰に何を渡すかを見てください。

IT と施設の取り合い

取り合いは、2 つの担当が接する境界です。計算サーバーでは、IT 側（機器）と施設側（建屋・設備）が、電力、冷却、床、ネットワークで接します。境界の両側で、持つものが違い、境界に「誰の仕事か」の空白ができやすいのが特徴です。

次の表は、責任の分け方の一般例です。実際は、案件ごとに決めて、取り合い表にして合意します。取り合い表は、設計の早い段階で作ります。工事や設置の段階で見つかると、手戻りになります。

マイルストーンと受入条件

案件の進み具合は、マイルストーン（節目）で測ります。各マイルストーンには、「何ができた状態か」と、それを確かめる受入条件を決めておきます。受入条件は、契約の前に決めます。契約の後だと、納入後に「合格かどうか」で争いになりやすくなります（第29章）。

リスクの洗い出し

案件の最初に、遅れや手戻りのもとになるものを洗い出します。この講座で扱ったものを、局面と持ち主の章で並べます。

  • 電力の確保：時間がかかることがある。案件の最初に、見通しを確かめる（第27章）。
  • 納期：機器だけでなく、設備と搬入の日程と合わせる（第28章、第29章）。
  • 液冷の取り合い：接続と冷却液の条件を、施設側と機器側で合わせる（第16章）。
  • 輸出管理：国をまたぐ機器の移動で、確認が要ることがある（第30章）。
この節の扱い

この節は制度の仕組みの説明です。個別の製品・技術・取引について、該非判定、許可の要否、取引の可否を判断するものではありません。実際の判断は、所管当局（日本では経済産業省 安全保障貿易管理の窓口）と、社内の輸出管理部門・専門家に確認してください。

輸出管理のリスクは、案件に国をまたぐ移動（海外の拠点、海外の保守拠点、再輸出）があるときに出ます。見積りの段階で、社内の担当に連絡することが、遅れを防ぎます。

議事録と変更管理

案件では、決定や変更が多く出ます。議事録に、決定事項、宿題、担当、期限を残します。後で「誰が、いつ、何を決めたか」を確かめる拠り所になります。

決めた内容を変えるときは、変更要求で扱います。変更の影響（納期・電力・費用）を確かめ、書面で合意します。口頭の変更は、記録に残らず、争いのもとになります。

総合演習

次の 8 ケースは、案件の場面です（すべて架空）。場面を読み、どの局面の問題かと、最初に動く担当を選びます。簡単なケースから並べています。答えの説明に、見るべき章を書いてあります。

つまずきやすい点

機器だけを見て、施設の条件を後回しにしないこと。電力、冷却、床、搬入の条件は、機器の性能と同じくらい、案件の成否を決めます。

もう一つ。「最初に動く担当」は、解決する担当とは限りません。演習は、まず確認と連絡を始める担当を問います。許可の要否のような判断は、権限を持つ担当と当局が行います。

現場でのつながり

案件の最初に、取り合い表、マイルストーンと受入条件、連絡先の一覧、議事録の置き場を作ります。変更は変更要求で扱い、記録を残します。用語に迷ったら、第32章の用語集を引きます。
