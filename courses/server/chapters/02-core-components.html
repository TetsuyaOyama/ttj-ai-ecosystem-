この章で分かること

  1. CPU・メモリ・ストレージ・ネットワークの 4 つの部品の役割と、性能の言葉（コア数、クロック、容量、帯域幅、遅延、IOPS）の違いを説明できる。
  2. メモリ階層（キャッシュ、メインメモリ、SSD、HDD）が、速さ・容量・電源を切ったときの扱いで分かれる理由が分かる。
  3. 帯域幅と遅延を区別し、処理の待ちを作る部品（ボトルネック）の探し方を言える。

前提：第01章（計算機の構成、データの流れ）。

4 つの部品と、それぞれの問い

第01章の「1 件の要求の処理」で、データは、ネットワーク、メモリ、CPU、ストレージの順に動きました。この章は、その 4 つの部品を、それぞれの性能の言葉で見ていきます。部品ごとに、「どれだけ速く」「どれだけ多く」「どれだけ待たせないか」という問いが違います。言葉を取り違えると、機器の比較を誤ります。

CPU：命令を実行する部品

CPU（Central Processing Unit、中央処理装置、プロセッサ）は、プログラムの命令を読んで実行する部品です。性能の言葉は、次のとおりです。

  • コア（core）：命令を実行する単位です。コアが多いほど、同時に進められる仕事が増えます。
  • スレッド（thread）：コアが受け持つ命令の流れです。1 つのコアが、複数のスレッドを同時に扱う方式（同時マルチスレッディング）もあります。その場合も、コアの演算器は、スレッドの間で分け合います。
  • クロック（clock）：命令を進める拍の速さです。単位は Hz です。同じクロックでも、1 拍にこなせる仕事は、設計によって違います。

コア数もクロックも、大きいほど速いとは限りません。仕事が並列に分けられなければ、コアを増やしても効果が出ません。また、CPU が待っていれば、クロックが高くても速くなりません。

CPU は、決められた命令セット（Instruction Set Architecture, ISA）の命令を実行します。命令セットは、ソフトウェアとハードウェアの約束です。サーバー向けに広く使われるのは、x86 と Arm です。

  • x86 の 64 ビット版は、Intel（米国）が「Intel 64」、AMD（米国）が「AMD64」の名前で、仕様を公開しています（出典：Intel『Software Developer Manuals for Intel 64 and IA-32 Architectures』のページ、AMD『AMD64 Architecture Programmer's Manual Volume 1』Rev. 3.25、2026 年 5 月）。AMD は、AMD64 を、従来の x86 を 64 ビットに拡張したもので、従来の x86 と下位互換がある、と説明しています（同出典）。
  • Arm（英国）は、命令セットなどの仕様を、パートナーにライセンスしています。パートナーは、その仕様に従うチップを作ります（出典：Arm『Arm Architecture』のページ、2026 年 11 月に確認）。

命令セットが違うと、同じプログラムをそのまま動かせません。サーバーを選ぶときは、動かすソフトウェアがどの命令セットに対応しているかを確かめます。CPU 製品の仕様値は、第06章で扱います。

キャッシュとメモリ階層

CPU は速いのに、メモリは相対的に遅いので、CPU が待たされます。この差を埋めるのがキャッシュ（cache）です。キャッシュは、CPU の中や近くに置く、小さくて速い記憶です。よく使うデータの写しを置いておき、CPU はまずそこを見ます。見つかれば速く、見つからなければメモリへ取りに行きます。

キャッシュが効くのは、プログラムが同じデータや近くのデータを、続けて使う傾向があるからです。この傾向があるので、小さな記憶でも、多くの読み出しを肩代わりできます（一般知識。教科書：Patterson・Hennessy 著『Computer Organization and Design』）。

記憶の部品は、速いものほど容量が小さく、遅いものほど容量が大きくなります。この段の並びをメモリ階層と呼びます。下の図で、各層の速さ・容量・電源を切ったときの扱いを確かめてください。数値は書いていません。

メインメモリ：作業台の広さ

メインメモリ（main memory）は、CPU が処理中のプログラムとデータを置く場所です。サーバーでは、DRAM（Dynamic Random Access Memory）が使われます。DRAM は、電源を切ると中身が消える揮発性の記憶です。容量は「作業台の広さ」にあたり、足りないと、データをストレージへ追い出すので、急に遅くなります。

DRAM の規格は、JEDEC（JEDEC Solid State Technology Association）が定めています。DDR5 SDRAM の規格の番号は JESD79-5 です（出典：JEDEC『JEDEC Publishes New DDR5 Standard…』、2020 年 7 月 14 日）。メモリの載せ方と世代ごとの速さは、第07章で扱います。

ストレージ：電源を切っても残る記憶

ストレージ（storage）は、電源を切ってもデータが残る記憶です。主な種類は 2 つあります。

  • HDD（Hard Disk Drive）：回転する円盤に、磁気でデータを書きます。容量あたりの費用を抑えやすく、読み書きは機械の動きを待ちます。
  • SSD（Solid State Drive）：半導体のメモリ（フラッシュメモリ）にデータを書きます。機械の動きがないので、HDD より待ちが短くなります。

ストレージの性能は、2 つの言葉で表します。IOPS（Input/Output Operations Per Second）は、1 秒に何回の読み書きをこなせるかです。スループット（throughput）は、1 秒にどれだけのデータ量を運べるかです。小さな読み書きが多い仕事（データベースなど）は IOPS が効き、大きなファイルを順に読む仕事は、スループットが効きます。

SSD には、書き換えられる回数に限りがあります。これを書き換え耐久性と呼びます。使い方によって寿命が変わるので、機器の選定では、仕様の耐久性の指標を確認します（指標の見方は第09章）。SSD の接続に使う NVMe（Non-Volatile Memory Express）は、NVM Express, Inc. が定める仕様の群です（出典：NVM Express, Inc.、2024 年 8 月 6 日の発表）。SSD の形状と接続の規格は、第09章で扱います。

ネットワーク：外とつなぐ部品

NIC（Network Interface Card）は、サーバーをネットワークにつなぐ部品です。カードの形でなくても、同じ役割の部品を NIC と呼びます。性能は、帯域幅と遅延で表します。

サーバーのネットワークには、通常、イーサネット（Ethernet）が使われます。IEEE 802.3 は、イーサネットの規格で、IEEE の標準規格です（出典：IEEE SA『IEEE Standard for Ethernet（IEEE 802.3-2022）』のページ、2022 年 7 月 29 日発行、現行の表示）。速さの世代とトランシーバは、第10章で扱います。

帯域幅と遅延：同じ「速さ」でも別のもの

帯域幅（bandwidth）は、単位時間に運べるデータ量です。遅延（latency）は、1 回の操作を始めてから結果が返るまでの時間です。道路にたとえると、帯域幅は道の車線数、遅延は端から端までの所要時間です。車線を増やしても、1 台が着くまでの時間は縮みません。

混同しやすいのが単位です。通信の帯域幅は、bit を使って「Gb/s」と書きます。メモリやストレージの帯域幅は、byte を使って「GB/s」と書くことが多いです。1 byte は 8 bit なので、数値を比べるときは、8 倍か 8 分の 1 の換算が要ります（一般知識）。

性能の言葉の早見表

ボトルネック：最も遅い部品が全体を決める

1 件の要求の処理は、4 つの部品を順に通ります。全体の速さは、最も待たされる部品で決まります。その部品をボトルネック（bottleneck）と呼びます。ボトルネックでない部品を速くしても、全体はほとんど変わりません。

探し方の手順は、次のとおりです。まず、各部品で、待ちの時間を測ります。次に、最も長い部品を見つけます。最後に、その部品の性能の言葉（IOPS、帯域幅、遅延、容量）のどれが足りないかを確かめます。

演習：待ち時間の内訳から、ボトルネックを選ぶ

次の表は、架空の処理 1 件の待ち時間の内訳です。ボトルネックの部品はどれで、その部品の何を見直しますか。考えてから、答えを開きます。

部品待ち時間 (ms)備考
ネットワーク2小さな要求と応答

メインメモリ1作業データの読み書き

ボトルネックは、待ち時間が最も長いストレージです。備考のとおり、小さな読み出しを何度も繰り返す仕事なので、見直すのは、スループットよりも IOPS と遅延です。たとえば、HDD から SSD への切替え、メモリの増設（キャッシュに残るデータを増やす）が選択肢になります。

CPU を速くしても、合計の待ち時間は大きく変わりません。ストレージの待ちが縮むと、次は CPU が最も長い部品になります。ボトルネックは、直すと次に移ります。

つまずきやすい点

Gb/s と GB/s を混ぜないこと。小文字の b は bit、大文字の B は byte です。同じ数字でも、byte は bit の 8 倍の量です。

もう一つ。帯域幅が大きい＝遅延が小さいとは限りません。大量に運ぶ力と、1 回の応答の速さは、別の性能です。

現場でのつながり

機器の選定や商談では、「速い」という言葉を、部品ごとの性能の言葉に直して聞きます。「何の待ちが問題か」が分かれば、CPU を増やすのか、メモリを足すのか、ストレージかネットワークかが決まります。
