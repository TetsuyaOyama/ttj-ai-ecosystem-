### 0.1 内容の決まり

`SPEC-COMMON.md` §1 のとおり。この講座で特に気をつける点：

1. **組み合わせ（第18〜20章）は「損益図を読むための説明」で、勧めない**。「相場が動かないと思うなら」「下落に備えるなら」のような、見通しと組み合わせを結びつける書き方をしない。各組み合わせは、**満期の損益の形・損益分岐点・最大の損失（限定か、限定されないか）・必要な証拠金の考え方**だけを書く。
2. **損益図には必ず損失の側を書く**（`SPEC-COMMON.md` §1-2）。オプションの売りの損失が限定されない場合は、図の注記と本文の両方に書く。
3. **価格のモデルは「考え方の道具」**。ブラック–ショールズ・モデルの前提（一定のボラティリティ・連続の取引など）と、市場の価格がモデルどおりにならないこと（スキュー）を必ず書く。モデルの価格を「正しい価格」「割安・割高の判定」と書かない。
4. **0DTE など近年の市場構造（第24・25章）は、事実と出典だけ**。取引所・当局・中央銀行・国際機関の公表の数字と、公開の研究の結論を、主体・資料名・公表日つきで引く。原因の解釈・相場への影響の評価を地の文に書かない。**公表された売買高から割合を自分で計算しない**（`SPEC-COMMON.md` §1-7）。
5. **指数の水準・オプションの価格・VIX・日経平均VI の値を書かない**（架空の値で示す。`SPEC-COMMON.md` §2.2-30）。架空の指数は「架空の指数 X（乗数 1,000 円）」の形で、実在の指数の水準と紛れない値（1,000 前後）を使う。

### 序章 オプションの入口

#### I1 オプションとは：権利の売り買い
- 要点：①オプションは「決められた価格で買う・売る**権利**」。②買い手は権利を持ち、オプション価格（プレミアム）を払う。売り手は義務を負い、オプション価格を受け取る。③コールは買う権利、プットは売る権利。④満期に権利を使うと得なら使い、損なら使わない（買い手の損失はオプション価格まで）。⑤売り手の損失は限定されないことがある（第21章）。
- 部品：`lab` **cI1-payoff**（架空の指数 X。入力：コールかプット・買いか売り・権利行使価格 K〔900〜1,100〕・オプション価格〔0〜100〕・満期の指数 S_T〔800〜1,200〕。結果：本質価値・損益〔円〕。`reads` に売りの損失の文）、`compare` **cI1-option-future**（オプションと先物：権利か義務か・最初の受払い・損失の範囲。講座 B 序1 へ）
- 問：オプションの買い手の損失がオプション価格までに限られる理由／売り手がオプション価格を受け取る理由（義務の対価）／コールとプットの権利の違い
- 演（架空）：コール K 1,000・価格 20、S_T 1,050 → ＋30,000 円、S_T 990 → −20,000 円。プット K 1,000・価格 15、S_T 950 → ＋35,000 円。
  - 検算の行：`検算 コール上: 30000 = (max(1050 - 1000, 0) - 20) * 1000`、`検算 コール下: -20000 = (max(990 - 1000, 0) - 20) * 1000`、`検算 プット: 35000 = (max(1000 - 950, 0) - 15) * 1000`
- 注意書き：投資、損失のリスク
- 事実：なし（架空）
- 持ち主：満期の損益の式（式 1〜4）

#### I2 損益図の読み方：満期の損益を描く
- 要点：①横軸＝満期の原資産の価格、縦軸＝損益。②折れ曲がりの点＝権利行使価格。③損益分岐点（コールの買いは K ＋ オプション価格）。④買いと売りは上下に反転した図。⑤満期の損益図と、途中の評価の線（理論価格の線）は別の図（第10・18章）。
- 部品：`lab` **cI2-diagram**（`curve`。入力は cI1 と同じ。満期の損益の線、損益分岐点の目印、0 の線。基盤の追加の前は `table` で S_T を 13 点）、`ident` **cI2-read**（損益図の読み方の解剖：横軸・縦軸・折れ曲がり・分岐点・最大の損失・最大の利益）
- 問：コールの買いの損益分岐点がオプション価格の分だけ上にある理由／売りの図が買いの図を上下に反転したものになる理由／満期の損益図と途中の評価の線の違い

  - 検算の行：`検算 分岐点: 1020 = 1000 + 20`
- 注意書き：投資、損失のリスク
- 持ち主：損益図の読み方（`GLOSSARY` の「損益図」の定義）
